**电桥关系（含有限开环增益的精确式，Lead 更正版）：**

```
V_o - V_REF = - (Z_f/Z_x) * (V_in - V_REF) / [ 1 + (1 + Z_f/Z_x)/A_ol ]
理想（A_ol -> inf）：Z_x = - Z_f * (V_in - V_REF)/(V_o - V_REF)
记 r = |Z_f|/|Z_x|，误差因子  eps0 = (1 + r) / A_ol
单极点运放、f >> f_p：A_ol = - j*GBW/f  =>  1/A_ol = + j*f/GBW
  => Z_meas = Z_x * (1 + j*eps)，eps = (1+r)*f/GBW（实数）
  => 相位误差 ≈ eps rad（一阶）；幅值误差 = sqrt(1+eps^2)-1 ≈ eps^2/2（二阶）
  => 若 A_ol 带实部（多极点/复合运放）：幅值误差退化为一阶 ≈ eps
```

量程设计取 `r = R_f/|Z_x|` 在 0.1–1 之间（见 E 节），故 `1+r` 在 1.1–2 之间，本报告取最坏 `r=1`，即 `eps = 2f/GBW`。

## B. 运放有限开环增益：相位是一阶、幅值是二阶

由第 0 节精确传递函数，`Z_meas = Z_x·[1 + eps0]`，`eps0 = (1+r)/A_ol`。单极点运放在 f≫f_p 时
`A_ol = -j·GBW/f`，所以 `1/A_ol = +j·f/GBW`，`eps0 = j·eps`，`eps = (1+r)·f/GBW`（实数）。于是

```
|Z_meas|/|Z_x| = sqrt(1 + eps^2)  =>  幅值相对误差 = sqrt(1+eps^2) - 1 ≈ eps^2/2   （二阶）
arg(Z_meas/Z_x) = atan(eps)         =>  相位误差 ≈ eps rad                   （一阶）
若 A_ol 带实部（多极点/复合运放）：因子 1+eps 为实数 => 幅值误差 ≈ eps/(1+eps)  （一阶）
```

取 r=1（Z_f=Z_x，即 β=0.5，量程窗口内最坏情况；r 在 0.1–1 时 `1+r` 在 1.1–2）。
原始简报里的 β=1 情形对应 r=0（Z_f≪Z_x），此时 `1+r`=1、ε=f/GBW，各误差恰为上表的一半——所以 r=1/β=0.5 这列才是保守值。

## C. 12 bit ADC + 单频点 DFT 的幅值/相位分辨率

### C.1 估算前提

```
LSB  q = ADC_FS/2^12；量化噪声 σ_q = q/sqrt(12)（均匀分布、白噪声假设）
相干采样（信号正好落在整数 bin）、单频点 DFT、矩形窗、高信噪比近似：
  复幅度估计 A_hat = 2|X_k|/N；幅度噪声 σ_A = σ_q*sqrt(2/N)；
  相位噪声 σ_φ = σ_A/A_peak （rad）；A_peak = sqrt(2)*|V_o,rms|
噪声按每通道独立处理，两通道比值：ε_|Z| = sqrt(ε_A(V_o)^2 + ε_A(V_in)^2)
```

q = 806 µV；σ_q = 233 µV；N=1024 时 σ_A = 10.3 µV（纯量化）；取 ENOB=10.5 时 σ_A,eff = 29.1 µV（×2.83）。

### C.4 相位误差对 C 值的影响（一阶体现在 D 上，不是 C 上）

```
纯电容 Z = -j/(ωC)：相位旋转 δ 后 |Z| 不变 => dC/C = δ^2/2（二阶）
有损耗电容（D=R/|X|）：C = 1/(ω·|Z|·sqrt(1+D^2))；相位误差 δ 使表观 D 变化 ≈ δ
  => dC/C ≈ D·δ（一阶项被 D 压小）
一般公式（Z=R+jX, Q=|X|/R）：dR/R = ε_A - Q·δ；dX/X = ε_A + δ/Q
```

若指标只由相位误差决定：纯 C 要达到 2% 的 C 值误差，允许 δ = sqrt(2×0.02) = 11.5°；要达到 0.5%，允许 δ = sqrt(2×0.005) = 5.73°。实际 2%/0.5% 指标主要由幅值精度承担（C.6），相位只要远小于上述上限即可。

| 相位误差 δ | δ (rad) | 纯 C: dC/C=δ²/2 | D=0.1 时 dC/C≈D·δ | D=0.01 时 dC/C≈D·δ | 表观 D 误差≈δ |
|------|------|------|------|------|------|
| 0.100° | 0.00175 rad | 0.000152% | 0.0175% | 0.00175% | 0.00175 |
| 0.573° | 0.0100 rad | 0.00500% | 0.100% | 0.0100% | 0.0100 |
| 0.115° | 0.00201 rad | 0.000201% | 0.0201% | 0.00201% | 0.00201 |
| 1.15° | 0.0200 rad | 0.0200% | 0.200% | 0.0200% | 0.0200 |

对应关系：0.1° 是题设通道相位失配；0.573° 是 20 MHz GBW 在 100 kHz 的运放相位误差；0.115° 是 100 MHz GBW；1.15°（0.02 rad）是 10 MHz GBW 在 100 kHz 的运放相位误差，旧 1/(Aβ) 公式会把它误当成 2% 的幅值误差（仅作对比）。

### C.4b 幅值/相位分辨率折算到 R 与 X 的相对误差（Q=10 与 Q=0.1）

由 `Z=R+jX`、`Q=|X|/R` 的一阶误差传播：`dR/R = ε_A − Q·δ`，`dX/X = ε_A + δ/Q`（δ 为相位误差，rad；ε_A 为 |Z| 幅值相对误差；两者独立时再 RSS 合成）。
取 N=1024、ENOB10.5 的量化/DFT 分辨率（相位误差 δ 与 ε_A 同源，按同量级代入）：
| \|V_o\| | Q | 相位分辨率 δ | 幅值误差 ε_A | dR/R（一阶） | dX/X（一阶） |
|------|------|------|------|------|------|
| 100 mVrms | 10.0 | 0.0120° | 0.0210% | -0.189% | 0.0231% |
| 100 mVrms | 0.100 | 0.0120° | 0.0210% | 0.0189% | 0.231% |
| 50.0 mVrms | 10.0 | 0.0237° | 0.0413% | -0.372% | 0.0455% |
| 50.0 mVrms | 0.100 | 0.0237° | 0.0413% | 0.0372% | 0.455% |

Q=10 时 dR/R 由 Q·δ 主导（|V_o|=0.1 Vrms 时 −0.19%，0.05 Vrms 时 −0.37%），Q=0.1 时 dX/X 由 δ/Q 主导（+0.23% / +0.46%）；两者都远小于 2% 指标，说明 ADC 分辨率不是限制，真正限制 R/X 分离的是相位误差（GBW、通道失配）——但 R/C/L 值本身只依赖 |Z| 与损耗修正，对纯元件的一阶影响仍是上面 C.4 的二阶结论。

### C.5 D 测量、元件类型判别所需的相位精度

```
分界 |X|/R = 0.1  <=> 阻抗角 atan(0.1) = 5.71°；
要求分界处 (X/R) 判别误差 ≤10%  =>  δ ≈ 0.01/(1+0.1^2) rad = 0.0099 rad = 0.567°
测 D 到相对误差 p：δ ≤ p·D（rad）
```

| 用途 | 所需相位精度 | 100 kHz 下用单极点运放 GBW 需 ≥ |
|------|------|------|
| 判别 R/C 分界 \|X\|/R=0.1，分界误差 ≤10% | 0.567° | 20.2 MHz |
| 测 D=0.1 到 10%（δ≤0.01 rad） | 0.573° | 20.0 MHz |
| 测 D=0.01 到 10%（δ≤0.001 rad） | 0.0573° | 200 MHz |
| 测 D=0.001 到 10%（δ≤0.0001 rad） | 0.00573° | 2.00 GHz |
| 测 D=0.01 到 1%（δ≤0.0001 rad） | 0.00573° | 2.00 GHz |

ADC 本身的相位分辨率（|V_o|=0.1 Vrms、ENOB10.5）约 0.0118°，远好于上述要求；真正的相位误差主导项是运放有限 GBW（B 节）与通道间相位失配 0.1°。

### C.6 2% 电容 / 1% 电阻 / 0.5% 电阻指标中，幅值误差预算还剩多少？

“已占”取 G 节校准后 RSS（除 ADC 量化/DFT 行）；ADC 占用取 |V_o|=0.05 Vrms 最差与 0.1 Vrms 典型。
| 指标 | 目标 | 其它项已占（校准后 RSS） | ADC 量化/DFT 占用 | 剩余 RSS 幅值预算 |
|------|------|------|------|------|
| C 2% | 2.00% | 0.211% | 0.0413% / 0.0210% | 1.99% / 1.99% |
| R 1%（1 kHz） | 1.00% | 0.0627% | 0.0413% / 0.0210% | 0.997% / 0.998% |
| R 0.5%（1 kHz） | 0.500% | 0.0627% | 0.0413% / 0.0210% | 0.494% / 0.496% |

即：ADC 量化/DFT（最差 |V_o|=0.05 Vrms、贡献 0.0413%）只占 2% 电容目标的约 2.1%、1% 电阻目标的约 4.1%；剩余预算几乎全部留给杂散、R_f 并联寄生、通道增益失配等（G 节），它们才是必须靠校准解决的项。

## D. 时序预算（单次测量 ≤ 1 s，100 Hz 档也要满足）

公式：
```
每档采集 10 个周期：T_acq = 10/f
N=1024 点相干采样所需采样率：f_s = N/T_acq = N·f/10 = 102.4·f
  （记录长度 10/f，正好 10 个整周期，落在 DFT 第 10 个 bin，无泄漏）
单遍 T1 = T_acq + 5 ms（量程切换/建立） + 10 ms（DFT） + 5 ms（显示）
量程搜索最坏重复 2 遍：T2 = 2·(T_acq + 5 + 10) + 5 ms
```

### D.2 100 kHz 档：1024 点 × 10 周期的采样率过高，改用多周期记录
100 kHz、10 个周期只有 100 µs，N=1024 要求 f_s = 10.24 MSPS；常见 MCU 内置 12 bit SAR ADC 只有约 2.4 MSPS，做不到。改用“记录 M 个周期、N 点”可降低 f_s：

```
f_s = N·f/M，记录长度 = M/f；幅度分辨率 ∝ sqrt(2/N)（N 越小越差）
```

| N | 记录周期数 M | f_s = N·f/M | 记录长度 | 单通道幅值分辨率（ENOB10.5，\|V_o\|=0.1 Vrms） | 可行性（内置 SAR ≈2.4 MSPS） |
|------|------|------|------|------|------|
| 1024 | 10 | 10.2 MSps | 100 µs | 0.0206% | 需外置高速 ADC 或降低 N |
| 1024 | 64 | 1.60 MSps | 640 µs | 0.0206% | 可用 |
| 256 | 12 | 2.13 MSps | 120 µs | 0.0411% | 可用 |
| 128 | 10 | 1.28 MSps | 100 µs | 0.0581% | 可用 |


取 N=256、M=12（f_s = 2.13 MSps）时，100 kHz 档单遍 T1 = 20.1 ms，两遍 35.2 ms，仍远小于 1 s；代价是幅值分辨率从 0.0206% 降到 0.0411%，仍远好于 2% 指标。

### D.3 100 Hz 档：多块平均
100 Hz 档 10 个周期 = 100 ms，单遍 120 ms、两遍 235 ms。若取 4 块平均提高信噪比 √4 = 2 倍：
`T = 4×(100+5+10) + 5 = 465 ms`（单量程）；两遍量程搜索最坏 `2×4×115 + 5 = 925 ms`，仍 < 1 s。

1. 6 档 R_f（10 Ω/100 Ω/1 kΩ/10 kΩ/100 kΩ/1 MΩ）覆盖 |Z_x| = 10 Ω–10 MΩ，R 10 Ω–1 MΩ 全部落在 ratio 0.1–1 内（1 MΩ 端点 ratio=1）。
2. R=10 Ω 不能配 R_f=100 Ω（ratio=10、|V_o|=5 Vrms 饱和）：正确做法是 (a) 增加 R_f=10 Ω 档（I=50 mA，需 100 mA 缓冲），或 (b) 把激励降到 0.05 Vrms（但违反 0.5 Vrms 测试电平指标）。

## F. 100 kHz 高频误差：夹具杂散与开路/短路校准

公式：
```
夹具并联杂散 C_p 并在 Z_x 上：C_meas ≈ C + C_p（两电容并联直接相加）
  未校准 C 相对误差 ≈ C_p/C；|Z| 相对误差 ≈ -C_p/C（一阶）
开路（只剩 C_p）：Z_open = Z_short + 1/(jωC_p)
短路（接触电阻 + 残余电感）：Z_short = R_s + jωL_s
两点校准：Z_x = (Z_m - Z_short)·Z_open / (Z_open - (Z_m - Z_short))
  理想情况下完全消掉 C_p；残余只来自 C_p 在“校准后/测量时”的变化 ΔC_p：
  ΔC/C ≈ -ΔC_p/C
```

### F.1 未校准：C = 10 pF，夹具并联杂散 C_p = 1 pF / 2 pF（100 kHz）
| C_p | 测得 C | C 相对误差 | \|Z\| 相对误差 | ≈C_p/C |
|------|------|------|------|------|
| 1.00 pF | 11.0 pF | 10.0% | -9.09% | 10.0% |
| 2.00 pF | 12.0 pF | 20.0% | -16.7% | 20.0% |

C=10 pF、C_p=1 pF 时未校准误差 +10%，2 pF 时 +20%，都远超 5% 指标——10 pF 档必须先做开路校准。

### F.2 开路 + 短路校准后的残余误差（C_p 漂移 ΔC_p）
| C_p 漂移 ΔC_p | 校准后 C | C 相对误差 | \|Z\| 相对误差 |
|------|------|------|------|
| 0（C_p 完全稳定） | 10.00 pF | -7.90e-8% | 7.90e-8% |
| 0.0500 pF | 10.0 pF | 0.500% | -0.498% |
| 0.100 pF | 10.1 pF | 1.000% | -0.990% |
| 0.200 pF | 10.2 pF | 2.00% | -1.96% |
| 0.500 pF | 10.5 pF | 5.00% | -4.76% |

说明：开+短路校准把 C_p 的一阶影响完全消掉；残余只取决于 C_p 的稳定性。要把 10 pF 的误差压在 5% 内，C_p 在校准与测量之间的漂移需 ≲ 0.5 pF；要 ≤2% 则需 ≲ 0.2 pF。

### F.3 与 Z_f 并联的寄生 C_f（量程电阻自身寄生）

R_f 的并联寄生 C_f 使有效反馈阻抗 Z_f,eff = R_f/(1+jωR_fC_f)，等效为乘性因子 A = 1+jωR_fC_f：
`Z_meas = A·Z_x`。于是 |Z| 偏 |A| 倍、相位移 arg(A)，且开+短路校准消不掉 A，必须做负载校准（第三标准）或在软件里按已知 C_f 修正。

|------|------|------|------|------|------|------|
| 10.0 kΩ | 1.00 pF | 100 kHz | 0.00197% | 0.360° | -0.00197% | 0.00628 |
| 100 kΩ | 1.00 pF | 100 kHz | 0.197% | 3.60° | -0.197% | 0.0628 |
| 100 kΩ | 2.00 pF | 100 kHz | 0.786% | 7.16° | -0.780% | 0.126 |
| 1.00 MΩ | 1.00 pF | 100 kHz | 18.1% | 32.1° | -15.3% | 0.628 |
| 1.00 MΩ | 1.00 pF | 1.00 kHz | 0.00197% | 0.360° | -0.00197% | 0.00628 |

* R_f=100 kΩ、C_f=1 pF、100 kHz 时 |A|-1 = 0.197%、相位 3.60°，按 |Z| 换算的 C 误差 -0.197%，表观 D≈0.0628——损耗角/ESR 类显示会被它污染。
* R_f=1 MΩ、C_f=1 pF 的极点只有 159 kHz；100 kHz 时 |A|-1 达 18.1%、相位 32.1°——1 MΩ 档在 100 kHz 不可用，这也是 E 节要求 1 MΩ 自动量程在 1 kHz 实现的原因。

### F.4 校准信号电平与短路校准风险

```
开路校准：Z_open ≈ 1/(jωC_p)（1 pF @100 kHz ≈ 1.59 MΩ）
  |V_o| = V_IN·R_f/|Z_open|；R_f=100 kΩ、1 pF 时 ≈ 31.4 mVrms（2 pF 时 62.8 mVrms）
短路校准：Z_short ≈ 0.1 Ω（+jω·20 nH = j0.0126 Ω @100 kHz）
  R_f=10 Ω 时若仍用 0.5 Vrms 激励：I = 5 A、|V_o| = 50 V —— 必须把激励降到 mV 级
```

|------|------|------|------|
| L = 10 µH @100 kHz | 6.28 Ω | 1.59% | 0.318% |

## G. 总误差预算

（数值单位均为 %；R 0.5% 与 R 1% 用同一组 R 列误差，因为误差机制相同。）

### G.3 主导项结论
1. **R（1% 与 0.5%）**：未校准 RSS = 0.589%，主导项是 ADC 两通道增益失配 0.58%（占 RSS 平方和约 96.1%），其次是 R_f 公差 0.1%。校准后 RSS = 0.0629%，主导项变为温漂/电源 0.05% 与引线 0.02%。
2. **C/L（2%）**：未校准 RSS = 1.18%，主导项是夹具杂散 C_p 1%（100 pF 档；10 pF 档为 10%）与通道增益失配 0.58%；校准后 RSS = 0.215%，由杂散残余 0.2% 与 R_f 并联 C_f 0.197% 主导。
3. **必做校准项**：R_f 标定（0.1%→0.02%）、ADC 两通道增益校准（0.577%→0.02%）、开路校准（C_p）、短路校准（0.1 Ω）；要消掉 R_f 并联 C_f 的乘性误差还需负载校准（第三标准）或已知 C_f 的软件修正。

### G.4 100 kHz 幅值误差主导项排序（按 Lead 指定顺序）
| 排序 | 误差源 | 未校准贡献 | 校准后贡献 | 措施 |
|------|------|------|------|------|
| 1 | 夹具/输入杂散 C_p | 1.00% | 0.200% | 开路校准 + 每次测量前重测 Z_open；10 pF 档未校准达 10% |
| 2 | R_f 并联寄生 C_f | 0.197% | 0.0200% | 负载校准或按已知 C_f 软件修正；1 MΩ 档 100 kHz 不可用 |
| 3 | ADC 两通道增益失配 | 0.58% | 0.020% | 两通道增益校准；注意未校准时它比 C_f 项更大 |
| 4 | 噪声（量化/DFT/前端） | 0.0410% | 0.0410% | \|V_o\|=0.05 Vrms 最差；多次平均可降 |

注意：**未校准**时 ADC 增益失配 0.577% 在数值上大于 R_f 并联寄生的 0.197%，只有在校准后（0.02%）才落到它之后；此排序对应“已做增益校准”的 100 kHz 幅值误差。

## H. 需要 Lead 注意的矛盾点 / 前提变化

1. **0.5 Vrms 测试电平与 +5 V 单电源/3.3 V ADC 满量程冲突。** ADC 直接耦合、偏置 2.50 V 时 |V_o| 只能到 566 mVrms，比值上限 1.13；ratio=1 时输出峰值 3.21 V，距 3.30 V 仅 92.9 mV，ADC 只用了 42.9% 满量程（等效损失约 1.2 bit）。建议交流耦合重新偏置到 1.65 V（|V_o| 上限 1.17 Vrms），或差分输出/前端衰减。
2. **“按 |Z| 窗口选频率”只适用于 C/L，对 R 无效。** R 的 |Z| 与频率无关，R 10 Ω–1 kΩ 与 100 kΩ–1 MΩ 段只能靠 R_f 量程和四线夹具；文档不要写成“R 也按窗口自动选频”。
3. **10 Ω 端点与 0.5 Vrms 电平矛盾。** R=10 Ω 若配 R_f=100 Ω，ratio=10、|V_o|=5 Vrms，物理上做不到；必须增加 R_f=10 Ω 档（I=50 mA，需 100 mA 缓冲）或把激励降到 0.05 Vrms——后者违反“测试电平 0.5 Vrms±10%”的指标。
4. **L=10 µH@100 kHz（6.28 Ω）超出 6 档 R_f 最小档能力。** R_f=10 Ω 时 ratio=1.59 > ADC 上限 1.13，|V_o|=0.796 Vrms、峰值 3.63 V（削顶）；需 4.7 Ω 档（ratio 0.748）或降低该档激励；此时电流 79.6 mA。这是 100 kHz 电感扩展指标最硬的端点。
5. **R=1 MΩ 的 0.5% 自动量程与 100 kHz 不能同时满足。** R_f=1 MΩ 并联 1 pF 的极点只有 159 kHz，100 kHz 下 |Z_f| 偏 18.1%、相位 32.1°；必须限定 1 MΩ 档只在 1 kHz 测量，文档中要写清这个前提。
6. **GBW 对幅值精度是二阶，不是主要矛盾。** 20 MHz GBW 在 100 kHz 下相位 0.573°、幅值误差仅 0.00500%；2% C/L 与 1% R 的幅值指标对 GBW 的要求只有约 2 MHz（单极点）/40 MHz（A_ol 有实部）。真正被 GBW 限制的是相位/D：0.573° 对应 D 误差 0.01000，测 D=0.01 到 10% 需 GBW≥200 MHz 或软件相位补偿；100 kHz 下测 D=0.001（需 2 GHz）不现实，只能靠相位标定或改在低频测。
7. **兼容“A_ol 有实部”的运放会让幅值误差退化为一阶。** 复合/多级运放在 100 kHz 处若 A_ol 带实部，20 MHz GBW 的幅值误差从 0.00500% 退化为 0.990%，直接吃掉 0.5% 自动量程指标——选型时要确认 100 kHz 处仍以单极点虚部为主，或做开环增益的相位/幅值标定。
8. **12 bit ADC + DFT 不是瓶颈。** |V_o|≥0.1 Vrms 时 |Z| 幅值分辨率优于 0.0206%，最差（0.05 Vrms）0.0413%；相位分辨率（|V_o|=0.1 Vrms）约 0.0118°，D 分辨率优于 1e-3；ADC 最差 0.0413% 只占 2% 电容目标的约 2.1%、1% 电阻目标的约 4.1%。剩余预算几乎全给校准/杂散/失配。
9. **开路+短路两点校准消不掉 R_f 并联寄生 C_f。** C_f 等效为乘性因子 A=1+jωR_fC_f：100 kΩ、1 pF、100 kHz 时 |Z| 误差 0.197%、相位 3.60°、表观 D=0.0628；开+短路校准后仍留 A。要彻底消除需加负载校准（第三标准）或在软件里按已知 C_f 修正。
10. **短路校准在 0.5 Vrms 下不可直接做。** R_f=10 Ω、Z_short=0.1 Ω 时 I=5.00 A、|V_o|=50.0 Vrms；必须把激励降到约 5.00 mVrms（I=50.0 mA）再校短路，并保证放大器/夹具能承受。
11. **两线夹具不满足 10 Ω 档 1% 指标。** 0.1 Ω 引线/接触在 10 Ω 上就是 1.00%，必须四线 Kelvin；文档要明确四线接法与开尔文夹。
12. **100 kHz 10 pF 指标（5%）完全取决于 C_p 稳定性。** C_p=1 pF 时未校准误差 +10%；开路校准后残余由 C_p 漂移决定：0.2 pF→2.00%，0.5 pF→5.00%。要满足 5% 需 C_p 在校准与测量间稳定在 ±0.25 pF 内，并每次测量前重做开路校准。
13. **12 bit SAR 采样率不够 100 kHz×1024 点×10 周期。** 需 10.24 MSPS；内置 2.4 MSPS 级 SAR 应改为 N=256/M=12（2.13 MSPS）或 N=1024/M=64（1.6 MSPS），代价是分辨率降到 0.04% 量级，仍远好于 2%。时序余量充足：最坏两遍 100 Hz 档 235 ms，4 块平均两遍 925 ms，均 < 1 s。
14. **频率误差 0.1% 与 C/L 值精度。** 若软件用标称频率换算 C/L，0.1% 频率误差直接进入结果；应当用实际采样时钟频率（晶振 50 ppm → 0.005%）计算，0.1% 只是显示频率与标称的偏差要求。
15. **误差预算总结。** R 1%：未校准 RSS 0.589%/最坏 0.793%（靠增益失配 0.58% 主导），校准后 0.0629%/0.142%；C/L 2%：未校准 RSS 1.18%/最坏 2.03%（夹具杂散 1% 主导），校准后 0.215%/0.402%；R 0.5%：未校准 0.589% 不通过，校准后 0.0629% 通过。必须靠校准：通道增益、开路、短路、R_f 标定；建议增加负载校准消除 C_f。
