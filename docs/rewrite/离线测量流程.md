## 帧处理与参数含义

输入排列为 `ADC1, ADC2, ADC1, ADC2, ...`，必须包含当前频点配置的完整样本对数。ADC 原始码必须在 0–4095 内。调用方保证缓冲实际长度，且处理期间不会被 DMA 改写。

实际频率由 `hse_hz * DDS_word / 2^28` 得到；拟合角频率来自 DDS 频率字与定时器分频的比值，因此共用 HSE 的绝对频差不改变拟合基函数。L/C 数值换算使用实际频率。`hse_hz` 未实测时使用标称 8 MHz，不能把该输入当作已经完成频率校准。

每次 `lcr_measure_frame` 都先清空输出并使 `valid=0`。只有全部处理成功才令 `valid=1`。拟合结果可以用于错误诊断，但诊断字段存在不代表阻抗有效。

| 参数 | 定义或可用条件 |
|---|---|
| Rs、Xs | 保留复数阻抗的实部、虚部，包含负号 |
| Ls | Xs > 0 时为 `Xs/ω` |
| Cs | Xs < 0 时为 `-1/(ω Xs)` |
| Rp | Rs > 0 时为 `|Z|²/Rs` |
| Lp | Xs > 0 时为 `|Z|²/(ω Xs)` |
| Cp | Xs < 0 时为 `-Xs/(ω |Z|²)` |
| Q | Rs > 0 时为 `|Xs|/Rs` |
| D | Rs ≥ 0 且 Xs ≠ 0 时为 `Rs/|Xs|` |

调用方必须检查 `available` 位再显示 L/C、Rp、Q、D 等字段；不可用字段的零值不是测得的零值。纯电抗的无限 Q 不输出为有效有限数。

类型判断是单频等效模型的初步判断：暂以 `|Xs| ≤ 0.02 Rs` 判为 R，其余按电抗正负判 L/C；当负实部幅度超过 `0.02 |Z|` 时输出 UNKNOWN。该边界尚未实测，不是误差指标。小于此边界的负实部可能来自量化或系统误差，仍保留原始负 Rs 并设置 `negative_resistance`，不伪造正 ESR，也不输出要求非负电阻的损耗参数。单频类型不能证明实际器件结构，自动选频和多频确认尚未实现。

## 校准参数的作用域

| 标记 | 生效内容 | 未提供时 |
|---|---|---|
| `LCR_CAL_CHANNEL` | 存 `alpha=G1/G2`，阻抗计算除以 alpha | alpha=1，明确为未校准 |
| `LCR_CAL_FEEDBACK` | 使用该量程的实际 Rf 与有效并联 Cf | 使用标称 Rf、Cf=0，不宣称实际寄生为零 |
| `LCR_CAL_FIXTURE` | 使用显式 Zs、Yo 做夹具补偿 | 不执行夹具补偿 |

每份参数记录带频率索引、量程索引和修订号。索引不匹配、未知标记或已启用字段非法都会拒绝。未启用的参数字段不参与计算。调度器在每次量程切换前复制一次校准参数，采集期间外部修改不会改变这一帧使用的快照。

这里实现的是参数消费和存储格式，尚未实现用户可操作的同源/开路校准采集流程。Zs/Yo 是模型系数，不能直接把开路测得的 Yopen 当作任意 Zs 下的 Yo，也不能把写入系数称为完成物理短路校准。短路流程仍按硬件核对记录保留实测门槛。

## 测量调度接入

1. 复位启动完成后初始化板级驱动，确认默认反馈闭合、DDS 静音、采集未启动，再调用 `lcr_session_init`。不得用重新初始化结构体的方法中止正在进行的 DMA/继电器动作。
2. 用 `lcr_session_io` 提供改频、启动采集、停止采集和可选校准查询回调。初始化/重初始化需要由调用方先建立默认 GPIO 状态；调度器不代替板级上电初始化。
3. 调用 `lcr_session_start` 指定频点、初始量程、是否自动量程和 HSE 频率。忙碌时或参数非法时返回 0，不替换正在运行的请求；调用方必须检查返回值。
4. 主循环持续调用 `lcr_session_poll`。继电器进入 READY 后才发起采集。启动回调携带频率、量程、样本对数和递增 token，必须异步返回，不能在回调内部立刻提交。
5. DMA 完成 ISR 只通知主循环。主循环调用 `lcr_session_submit` 并传回该次采集的 token；函数先调用停止采集回调，要求回调返回后缓冲保持不变。调用方还应提供匹配的样本对数，不能仅因 token 正确便提交其他配置的缓冲。
6. 只有状态为 `LCR_SESSION_DONE` 且 `result.valid` 时发布新测量结果。中间量程帧、过期/重复 token、取消、超时和硬件回调失败都不发布有效结果。

状态机、校准更新和帧提交都由同一个主循环拥有，不能从 ISR 并发调用，也不能复制运行中的 session。令牌跳过零，用于区分同一实例中的采集请求；它不是跨 MCU 复位或重新初始化后的持久请求身份。

结束、失败和取消都会请求停止采集和静音。继电器仍在动作时，继续运行释放/吸合等待，完成目标反馈闭合后才结束 STOPPING。通信失败会锁存故障；软件不能据失败返回值保证物理激励已静音。

## 自动量程策略与时间边界

先检查 V1 是否削顶、过弱或残差过大；这些情况不靠切换反馈电阻修复。V2 削顶或幅度过高则减小 Rf，幅度过低则增大 Rf；V2 幅度足够而失真明显时拒绝帧。

当前暂用 80 码峰值作为下界，上界取 `min(1400码, 0.85×直流偏置两侧余量)`。这些是待实测调整的动态范围阈值，不是精度保证。记录访问过的六档量程，禁止回访；到达端点或出现反向回访时报告 RANGE_LIMIT，不无限往返切换。

每次采集超时取标称帧时长向上取整后加 100 ms。继电器控制当前每次切换仍含 800 ms 模拟稳定等待，因此多档搜索可能明显超过 1 s。合成测试推进的是模拟毫秒值，不测 MCU 执行速度，不能据此宣称单次时间达标。

## 校准记录格式 v1

固定长度 **1772 字节**，整数显式小端编码，double 显式 IEEE 754 binary64 编码，不直接保存 C 结构体及其填充字节。仅支持符合该浮点格式的平台。

| 偏移 | 长度 | 内容 |
|---|---|---|
| 0 | 4 | ASCII `LCR1` |
| 4 | 4 | 格式版本 1 |
| 8 | 4 | 总长度 1772 |
| 12 | 4 | sequence，由未来存储事务管理器维护 |
| 16 | 4 | 非零 board_id |
| 20 | 4 | 非零 fixture_id |
| 24 | 8 | HSE 实际/标称频率，Hz |
| 32 | 4 | 保留，必须为 0 |
| 36 | 4 | 槽位数 24 |
| 40 | 1728 | 按频率优先、量程次序排列的 24 个槽位，每槽 72 字节 |
| 1768 | 4 | 前 1768 字节的 CRC32/ISO-HDLC |

每槽依次为 flags、revision（各 4 字节），再为 alpha.re、alpha.im、Rf、Cf、Zs.re、Zs.im、Yo.re、Yo.im（各 8 字节）。槽位坐标由位置确定，解码时重建。

解码要求外部提供匹配的 board_id/fixture_id；编号需要由后续实际系统明确维护，当前没有自动生成或识别实物身份。错误长度、CRC、版本、保留字段、槽位数、身份或参数语义都会拒绝；失败不修改已有输出。CRC 用于检错，不代表记录来源已经验证。

当前没有 MCU Flash 擦写、双记录选择、掉电事务或磨损管理。损坏/截断测试只验证该记录会被拒绝，不证明保存时掉电后仍保有上一份记录。
