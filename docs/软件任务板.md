# 软件任务板（共享认领）

> 规则见 `docs/软件协作交接说明.md` §4/§11。**认领前先读任务对应的架构文档章节**。
> 写作用域 = 该任务允许修改的文件/目录；**同一文件同一时间只能有一个 owner**。
> 状态：`未认领` / `进行中(名字)` / `待 review(名字)` / `完成`。每次只改自己那一行的"状态/owner/备注"，减少冲突。
> 任务完成后把状态改"完成"并在"提交"列填 commit 短哈希；里程碑完成打 tag（与架构文档 §11 对齐）。
