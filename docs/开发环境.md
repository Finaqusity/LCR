## 3. 三条命令

在仓库根目录（`D:\0-Documents\电子设计\电赛校队招新_测量题`）执行：

```powershell
# 编译（Debug）
powershell -ExecutionPolicy Bypass -File tools\build.ps1

# 编译（Release，-O2）
powershell -ExecutionPolicy Bypass -File tools\build.ps1 -Release

# 清理重编
powershell -ExecutionPolicy Bypass -File tools\build.ps1 -Clean

# 烧录（默认 stm32f407vetx，烧 firmware\build\lcr-fw.hex）
powershell -ExecutionPolicy Bypass -File tools\flash.ps1

# 看串口（自动找 COM 口，115200）
python tools\monitor.py
python tools\monitor.py --list          # 列出串口
python tools\monitor.py --port COM4 --baud 115200 --log uart.log
```

产物：`firmware/build/lcr-fw.elf`、`lcr-fw.hex`、`lcr-fw.bin`、`lcr-fw.map`。

## 6. 构建系统里已经踩过的坑（改 CMake 前必读）

1. **必须加** `set(CMAKE_TRY_COMPILE_TARGET_TYPE STATIC_LIBRARY)`（否则 CMake 链接测试程序报 `undefined reference to _exit/_close/_sbrk`）。
2. PowerShell 里 `-DCMAKE_BUILD_TYPE=$gen` **必须整段加引号**：`"-DCMAKE_BUILD_TYPE=$gen"`，否则 cache 里写进字面量 `$gen`，ninja 报 `expected newline`。
3. `-specs=nano.specs` **只能加一次**（重复会 `attempt to rename spec 'link'`）。
4. POST_BUILD 的 objcopy 用**相对文件名** `$<TARGET_FILE_NAME:lcr-fw>`（绝对中文路径经 cmd 会乱码）。
5. 所有 `.ps1` 必须存成 **UTF-8 with BOM**（Windows PowerShell 5.1 会把无 BOM 的 UTF-8 当 GBK，报 `Unexpected token`）。
6. 链接时出现 `_close/_lseek/_read` 等 warning 是 `-specs=nosys.specs` 的正常现象，忽略即可。

## 7. 烧录/调试常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| `pyocd list` 显示 "No available debug probes" | DAPmini 没插/驱动异常 | 换 USB 口；设备管理器看有无 `CMSIS-DAP` |
| `No ACK received` / 连接失败 | SWD 线序错或目标没供电 | 检查 SWDIO/SWCLK/GND/3V3 四根；先给板子上电 |
| 烧录后不运行 | BOOT0 被拉高 | 把 BOOT0 跳线拨回低电平，复位 |
| `pyocd flash` 报 unknown target | 器件包没装 | `pyocd pack install stm32f407vetx` |
| 串口无输出 | CH340 未识别 / 波特率 | 装 CH340 驱动；确认 115200 8N1；PA9/PA10 交叉 |
| 编译报 `arm-none-eabi-gcc not found` | 脚本没找到工具链 | 检查 `D:\Tools\embedded\arm-gcc-14.2\bin` 是否存在 |

## 8. 建议的固件分层（新建文件时照这个来）

```
firmware/Core/
  Inc/board.h        # 时钟、SysTick、延时、LED
  Inc/uart.h         # 串口 + printf 重定向
  Inc/dds.h          # AD9833（SPI1 + FSYNC）
  Inc/relay.h        # 六档 + 校准开关（PD0–PD6）
  Inc/adc.h          # ADC1/2 双同步 + TIM8 TRGO + DMA + DFT
  Inc/meas.h         # Zx 计算、类型识别、量程决策
  Inc/cal.h          # α / 开路 / 短路 / 负载校准，Flash 存储
  Src/*.c
```

`main.c` 只做：初始化 → 自检 → 菜单/串口命令 → 循环。
