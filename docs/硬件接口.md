## 0. 一句话架构

```
AD9833(DDS) → C1 10µF → R1 10k → U12A OPA2810(反相放大) → U13 BUF634A → TP1=F+
   → 四端夹具(F+/S+/F−/S−) → DUT → F−(虚地 3.3V)
   → U15 OPA2810(I-V) → U16 BUF634A → VO
   → 两路 RC(K7 校准开关) → 1µF 隔直 → 100k 到 VBIAS 1.65V
   → U19A/U19B OPA2320 跟随 → 100Ω+1nF → BAT54S 钳位 → PA0 / PA1
```

- **测量式**：`Zx = −Zf · α · (Vin/Vo)`（复数，Vin=CH1=PA0，Vo=CH2=PA1，α 为通道失配校准系数）
- 六档 Rf：10 Ω / 100 Ω / 1 kΩ / 10 kΩ（默认）/ 100 kΩ / 1 MΩ，继电器切换
- 四个频率：100 Hz / 1 kHz / 10 kHz / 100 kHz；`fs = 16·f0`，`N = 1024`，`M = 64` 周期相干采样

## 3. 继电器（量程 + 校准）

### 3.1 逻辑映射（固件只认这个表）

| GPIO | ULN 通道 | 网络名 | 功能 | 吸合后 |
|---|---|---|---|---|
| PD0 | 1 | `K18` | **10 Ω 档** | R23(10 Ω) 接入 |
| PD1 | 2 | `K28` | **100 Ω 档** | R25(100 Ω) 接入 |
| PD2 | 3 | `K38` | **1 kΩ 档** | R26(1 kΩ) 接入 |
| PD3 | 4 | `K48` | **10 kΩ 档（默认）** | **断开**该档（常闭时接入） |
| PD4 | 5 | `K58` | **100 kΩ 档** | R28(100 kΩ) 接入 |
| PD5 | 6 | `K68` | **1 MΩ 档** | R29(1 MΩ) 接入 |
| PD6 | 7 | `K78` | **校准开关** | 两路输入切到 CAL |

- **默认状态**：所有 GPIO = 低 → 只有 10 kΩ 档在回路里（K48 用常闭触点），I-V 不会开环。
- 切换某档：先全部拉低（断开）→ 延时 5 ms → 目标档拉高 → 延时 10 ms → 采样。**同一时刻只允许一只吸合**（同时 7 只约 148 mA，5 V 轨会塌）。
- 继电器动作时间 ≤3 ms，10 ms 余量足够。

### 3.2 ⚠️ PCB 位号与网络名不一致（重要）

PCB 实际位号是打乱过的，**按网络名/GPIO 编程，不要按 PCB 丝印的 K 编号**：

| 网络名 | 功能 | PCB 位号 |
|---|---|---|
| `K18` | 10 Ω | **K2** |
| `K28` | 100 Ω | **K4** |
| `K38` | 1 kΩ | **K3** |
| `K48` | 10 kΩ | **K6** |
| `K58` | 100 kΩ | **K7** |
| `K68` | 1 MΩ | **K5** |
| `K78` | 校准 | **K1** |

调试/焊接时对照此表；固件只需 `RELAY_10R = PD0` … `RELAY_CAL = PD6`。

## 4. AD9833（DDS 激励源）

- 供电 3V3A；MCLK = **MCO1 8 MHz**（PA8），SPI1 写寄存器。
- 输出：0.6 Vpp 典型（正弦），经 C1 隔直后进放大链；幅度靠 VR1 校准到 TP1 = 0.5 Vrms。

### 4.1 频率字

```
FREQREG = round( f_out × 2^28 / MCLK )     // MCLK = 8 000 000 Hz
         = round( f_out × 33.554432 )
```

| f_out | FREQREG（十进制） |
|---|---|
| 100 Hz | 3355 |
| 1 kHz | 33554 |
| 10 kHz | 335544 |
| 100 kHz | 3355443 |

### 4.2 写时序（每次 16 位，FSYNC 低有效）

1. `PA4 = 0`（FSYNC 拉低）
2. SPI1 发送 2 字节（MSB first，16 位一帧）
3. `PA4 = 1`

初始化序列（正弦输出）：

```
0x2100    // 控制字：B28=1（28 位写）、RESET=1
0x4000|LSB14   // 频率寄存器 0 低 14 位
0x8000|MSB14   // 频率寄存器 0 高 14 位
0x2000    // 控制字：清 RESET，OPBITEN=0、MODE=0 → 正弦
```

（地址位：D15:D14 = 00 控制寄存器、01 → 14 位 LSB、10 → 14 位 MSB。）

SPI1 配置建议：主机、16 位、MSB first、软件 NSS、**模式 1（CPOL=0, CPHA=1）**（SCLK 下降沿取样），`PCLK2/2 = 42 MHz` 或更低（AD9833 最高 SCLK 40 MHz）。FSYNC 由 GPIO 控制，不用硬件 NSS。

## 5. ADC 采样（双通道同步）

### 5.1 配置

| 项 | 值 |
|---|---|
| 通道 | ADC1_IN0（PA0，Vin）；ADC2_IN1（PA1，Vo） |
| 模式 | **双重规则同步**（ADC1 主、ADC2 从，同一时刻转换） |
| 触发 | 定时器 TRGO → ADC1 外部触发上升沿；ADC2 由 ADC1 触发（Dual regular simultaneous） |
| 分辨率 | 12 位 |
| 采样时间 | 3 个 ADC 周期（1.6 MHz 时 15 周期 @28 MHz = 0.54 µs < 0.625 µs 周期） |
| 数据 | 公共数据寄存器 `ADC->CDR`：低 16 位 = ADC1，高 16 位 = ADC2 |
| DMA | DMA2 Stream0 Channel0，循环模式，32 位宽，目标 `uint16_t buf[N][2]` 或 `uint32_t buf[N]` |

> ⚠️ 必须用 DMA 循环缓冲双缓冲（半满/全满中断），不要在中断里逐个读 CDR，1.6 MHz 时来不及。

### 5.2 采样率与定时器（关键：100 kHz 档必须用 168 MHz 的定时器）

`fs = 16 × f0`：

| f0 | fs | 定时器 | ARR（PSC=0） |
|---|---|---|---|
| 100 Hz | 1.6 kHz | TIM8（168 MHz） | 104999 |
| 1 kHz | 16 kHz | TIM8 | 10499 |
| 10 kHz | 160 kHz | TIM8 | 1049 |
| 100 kHz | 1.6 MHz | TIM8 | **104** |

- **用 TIM8（APB2，168 MHz）的 TRGO（更新事件）触发 ADC**，ADC `EXTSEL = 0110`（TIM8_TRGO）。
- 若用 TIM2（84 MHz）：前三档 ARR = 52499 / 5249 / 524 可以精确，但 1.6 MHz 需要 52.5（非整数）→ 100 kHz 档会偏 1%，直接不达标。**所以统一用 TIM8**。
- 每档采样：N=1024 点 → 100 Hz 档 0.64 s、1 kHz 档 64 ms、10 kHz 档 6.4 ms、100 kHz 档 0.64 ms。

### 5.3 DFT（单 bin，相干）

```
对 k = 0..N-1：I += x[k]·cos(2πk·M/N)，Q -= x[k]·sin(2πk·M/N)   // M = 64
复数 = I + jQ，幅度 = 2·|X|/N · (1/2 归一化按 ADC 满量程处理)
```

- 先减去均值（去 DC），再加 Hann 窗（可选，相干采样时矩形窗即可，Hann 会让幅度差 0.5，别混用）。
- 表法：预存 `sin/cos` 表 1024 点 × M 步进（1024×64=65536 距离太大，直接按 `2π(M·k mod N)/N` 查 1024 点表）。
- 结果：`Vin = I1 + jQ1`、`Vo = I2 + jQ2`，`ratio = Vin / Vo`。

## 6. 测量流程（固件主循环）

1. **选频**：按用户设定或自动（C 用最高频、L 用最低频、R 用 1 kHz）。
2. **选档（自动量程）**：
   - 默认 10 kΩ 档粗测一次 → 得 |Zx|、类型；
   - 目标：`|Vo|/|Vin|` 落在 0.1–1；
   - 切到目标档（先断后吸），再测；
   - 最多重试 3 次（每次几毫秒），满足"单次 ≤1 s"。
3. **校准**（首次开机/每次上电/换夹具后）：
   - `α`：PD6 拉高（两路接 CAL）→ 采一组 → `α = m1/m2`（复数）→ PD6 拉低；**每个频率做一次**；
   - 开路：夹具空置，测每个 Rf 档的 `Z_open`；
   - 短路：粗铜线短接夹具，测每个 Rf 档的 `Z_short`（10 Ω 档注意：激励要降到 ~5 mVrms，或直接用软件限幅保护，否则电流 50 mA 也还好，但触点在 10 Ω 档发热）；
   - 负载：1 kΩ 0.1%（可选，校正 Rf 绝对值与触点电阻）。
   - 校准值存内部 Flash（`0x0807F000` 之后 1 页，留 padding）。
4. **测量**：切档 → 采 1024 点 → DFT → `Zx = −Zf·α·(Vin/Vo)` → 开路/短路修正：
   ```
   Zx = (Zm − Zshort)·(Zopen − Zshort) / (Zopen − Zm)
   ```
5. **计算**：`R = Re(Zx)`、`|Z| = |Zx|`、`φ = arg(Zx)`
   - `|φ| < 10°` → 电阻，显示 R
   - `φ ≈ −90°` → 电容，`C = 1/(2πf|X|)`，`X = Im(Zx)`
   - `φ ≈ +90°` → 电感，`L = |X|/(2πf)`
   - 同时给 `D = R/|X|`（或 `Q = |X|/R`），按串联模型
6. **显示**：类型 + 数值 + 单位 + 频率 + 量程 + 相位。

## 7. 串口协议（建议，ASCII 行协议，115200 8N1）

| 命令 | 作用 | 返回 |
|---|---|---|
| `?` | 帮助 | 命令列表 |
| `F 1000` | 设频率（100/1000/10000/100000） | `OK F=1000` |
| `R 3` | 设量程（0=10Ω,1=100Ω,2=1k,3=10k,4=100k,5=1M） | `OK R=3` |
| `A` | 自动量程 + 自动选频测量一次 | `Z=... R=... phi=... type=...` |
| `M` | 测一次（当前设置） | 同上 |
| `CAL A` | 通道失配 α（当前频率） | `OK alpha=...` |
| `CAL O` | 开路校准（所有档） | `OK` |
| `CAL S` | 短路校准（所有档） | `OK` |
| `RAW ON` / `RAW OFF` | 原始 ADC 流（调试） | `OK` |

## 8. 关键电平与误差预算（写代码时的假设）

| 信号 | 直流 | 交流（100 Hz–100 kHz） |
|---|---|---|
| VREF_AFE（虚地） | 3.300 V | 0 |
| TP1 = F+ | 3.3 V | 0.5 Vrms（1.414 Vpp），±10% 题目要求，内部校准到 ±1% |
| S+（DUT 上端） | 3.3 V | 取决于 Zx：2.59–4.01 V 包络（0.5 Vrms 时） |
| F−（求和节点） | 3.3 V（虚地） | ~0（mV 级） |
| VO（I-V 输出） | 3.3 V | 0.05–0.5 Vrms（量程窗口） |
| ADC 输入 | 1.65 V（VBIAS） | ±0.707 V（3.3 V ADC、1.65 V 中点） |
| 9 V 轨 | 9.0 V | 纹波 <1 mVrms |

- ADC 满量程 3.3 Vrms → 12 位 LSB ≈ 0.8 mV；1.6 MHz 相干采样 + 1024 点 DFT 的噪声带宽约 1.5 kHz。
- 10 pF 档：夹具杂散 1 pF = 10% 误差 → **必须做开路校准**，且夹具不许随手移动。

## 9. 上电自检 / 调试顺序

1. 只焊电源：量 5 V、3V3、3V3A、9 V（8.8–9.2）、VDDA、VREF_AFE（3.300±0.05）、VBIAS（1.650±0.01）；纹波 <1 mVrms。
2. 焊 MCU：SWD 能连、串口打印启动横幅、PC13 心跳 1 Hz。
3. 焊 DDS：示波器看 TP1，4 个频点波形干净、幅度 0.5 Vrms。
4. 焊 I-V：夹具短路 → 读数 ≈0 Ω（<50 mΩ）；接 1 kΩ 0.1% → 读数 ±1%。
5. 焊通道/ADC：两路 DFT 幅度一致性、α 校准前后差。
6. 全部装配后：跑一遍 16 项验收表（见 `硬件设计-六层板.docx` 第 11 节）。

## 10. 已知硬件注意点（固件要兜底）

1. **VREF_AFE 只在 U9 端有去耦**，U17（I-V）侧 37 mm 无电容 → 100 kHz 时参考可能轻微抖动；固件不要依赖单次测量，做 3 次中值/平均。
2. **没有 M3 安装孔**，板子只能平放或胶粘；振动/移动会让夹具杂散变化 → **测 10 pF 档前先做开路校准**。
3. **L1/L4 无铺地**，BNC 外壳靠过孔接地；夹具电缆不要超过 30 cm。
4. **继电器触点电阻 0.1 Ω 量级**：10 Ω 档误差 1%，靠负载校准吸收；固件校准表按档存 Rf 实际值（用负载校准拟合）。
5. **BOOT0 跳线**：烧录后务必拉回低，否则复位进 DFU。
6. 板上 4 个 BNC：F1=F+、S1=S+、F3=F−/S−、S2=F−/S−（S− 与 F− 在夹具端短接）。
