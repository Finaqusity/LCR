## 三、使用提醒

- 查寄存器位定义时**优先用仓库内头文件**：`firmware/Drivers/CMSIS/Device/ST/STM32F4xx/Include/stm32f407xx.h`（裁剪版，仅 F407）与 `firmware/Drivers/STM32F4xx_HAL_Driver/Inc/*.h`（HAL/LL 头，仅作位定义参考，不编译）。
- 查“这个器件实际是什么参数”时，先看 `docs/硬件接口.md`；与 `docs/软件架构.md` §14.1 冲突以架构文档为准。
- 新增数据手册：PDF 放本机 `_ds/`（不要 `git add -f`），在本文件“一、本机已有”表里加一行即可。
