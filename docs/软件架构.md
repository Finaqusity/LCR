### 1.2 硬件平台摘要（软件视角）

```
                    ┌───────────────────────── STM32F407VET6 (168 MHz) ─────────────────────────┐
  8 MHz XO ──► HSE ─►│ PLL ──► SYSCLK 168 / AHB 168 / APB1 42 / APB2 84 / ADC 21 MHz            │
                     │                                                                          │
                     │  MCO1(PA8) ──8 MHz──► AD9833 MCLK                                        │
                     │  SPI1(PA5/PA7)+FSYNC(PA4) ──► AD9833 频率字 ──► 正弦 0.6 Vpp ──► 放大链 ──► F+ │
                     │                                                    (VR1→TP1=0.5 Vrms)    │
                     │  PD0..PD6 ──► ULN2803 ──► 7 只继电器（6 档 Rf + 1 只 CAL）                 │
                     │                                                                          │
  F+ ──► Zx ──► 虚地(VREF_AFE=3.3 V) ──► I-V(Zf=Rf) ──► Vo ──► 缓冲/偏置 1.65 V                 │
   │                     ▲                     │                                                 │
   └─ S+ ──RC──► PA0 ADC1_IN0 (Vin)           └─► PA1 ADC2_IN1 (Vo)  ◄── 双 ADC 同步 + TIM2 TRGO │
                     │                                                                          │
                     │  USART1 PA9/PA10 ──► CH340 ──► PC；I2C1 PB6/PB7 ──► OLED；PC13 LED       │
                     └──────────────────────────────────────────────────────────────────────────┘
```

关键器件/资源（详情见 `docs/硬件接口.md`）：

- **DDS**：AD9833，MCLK = HSE 8 MHz（MCO1 直出，不由 PLL 分频），10 bit DAC，输出幅度固定、无数字幅度控制；正弦频率字 `FREQREG = round(f × 2^28 / 8e6)`。
- **模拟前端**：自动平衡电桥。DDS→隔直→放大→F+；被测件 Zx 接在 F+ 与虚地（VREF_AFE=3.3 V）之间；I-V 转换器把流过 Zx 的电流经 Rf 转成 Vo；Vo 与 Vin 经 RC 抗混叠后进两路 ADC；VBIAS=1.65 V 为 ADC 输入偏置。
- **量程**：6 只继电器选择 Rf = 10 Ω / 100 Ω / 1 kΩ / 10 kΩ / 100 kΩ / 1 MΩ；第 7 只（K78/CAL）把输入切到校准网络。**档位互锁**：同一时刻只允许一个量程档有效；10 kΩ 档为常闭（NC）默认档，选其他档时必须同时吸合“目标档 + K48(10 kΩ 档)”两只线圈（约 42 mA）；7 只全吸 148 mA **是否会拉塌 5 V 轨未实测**（按最坏禁止，§4.3 协议）。
- **采样**：ADC1_IN0=Vin（主）、ADC2_IN1=Vo（从），双重规则同步模式，TIM2 TRGO 触发，DMA2 Stream0 循环搬运 `ADC->CDR`（低 16 位=ADC1，高 16 位=ADC2）。
- **人机**：USART1 115200 → CH340；I2C1 OLED（SSD1306 类 128×64）；PC13 LED（低电平点亮）。**引脚表中没有用户按键**，PD7 为备用输入下拉。

### 1.5 架构设计原则

1. **相干采样 + 相敏检测**：每块采样的采样率与信号频率严格成整数比（fs = S·f0，N = M·S），矩形窗无泄漏；相位/幅度由 DFT 单 bin 得到，不做模拟检波、不依赖 ADC 采样相位。
2. **复数域测量，实部虚部分开标定**：所有误差（通道失配、夹具、Rf、触点）都建模为复数乘性/加性项，标定即“测出这些复数项”，测量即“反解”。
3. **分层单向依赖**：应用层 → 测量内核 → 驱动层 → BSP/寄存器；禁止反向调用与跨层直写寄存器（唯一例外：ISR 中标记事件，由内核消费）。
4. **表驱动**：频率、采样参数、量程、校准、显示单位全部由只读表 + 校准记录驱动，新增频率/档位只需改表，不改流程。
5. **可观测**：测量链每个中间量（Vin/Vo 复数、α、Z_open/Zp(双负载)、块间方差、谐波比、继电器状态、DDS 频率字）都能通过串口导出，供台架调试与验收取证。
6. **可测试**：纯计算模块（DFT、阻抗反解、量程决策、类型识别）与硬件解耦，可在 PC 上用 gcc/numpy 金标准向量单测（§11.1）。

### 2.2 频率精度：0.1% 要求如何保证

**结论：软件端误差 ≤0.014%，加晶振误差后仍 ≤0.02%，余量 ≥5 倍。关键是必须使用 HSE 而不是 HSI。**

| 误差源 | 数值 | 说明 |
|---|---|---|
| HSE 8 MHz 晶振 | 典型 ±10–30 ppm（0.001–0.003%） | 硬件 BOM 决定；PLL 与 DDS 同源，频率**比值**无误差 |
| PLL 倍频抖动 | 0（锁定后） | 必须轮询 `RCC_CR.PLLRDY` 再切换 SYSCLK |
| AD9833 频率字量化 | 100 Hz：−0.0132%；1 kHz：−0.0013%；10 kHz：−0.00013%；100 kHz：−6×10⁻⁶% | `FREQREG = round(f·2^28/8e6)`；2^28/8e6 = 33.554432 |
| 采样时钟（TIM2） | **0** | 84 MHz/(S·(ARR+1)) 恰好等于 100/1k/10k/100k Hz，且与 DDS 共用 HSE，相干条件严格成立 |
| 温度/老化 | ppm 级 | 短时测量可忽略；`VER` 命令输出运行时间与温度（如加片内温度传感器）可选 |

软件措施：
1. `FREQREG = (uint32_t)((f_hz * 2^28ULL + 4 000 000) / 8 000 000)`（64 位中间量，四舍五入），不用浮点。
2. `TIM2->ARR = 84 000 000 / (S × f0) − 1`（32 位，PSC=0）；同时把 `S`、`ARR`、`N`、`M` 一起写入采样配置结构，供 DFT 使用。
3. 显示与返回给上位机的 `f` 用标称 `f0`；内部计算 C/L 时用 `f_dds = FREQREG × 8e6/2^28`（AD9833 实际频率，误差 ≤ −132 ppm，见 §5.2）。
4. 若今后增加任意频点：f0 与 fs 必须同时由同一时钟派生（`fs = 84e6/(ARR+1)`、`f0 = fs/S`），否则相干性破坏，单 bin DFT 出现泄漏。

### 2.3 电平与幅度：0.5 Vrms 的软件角色

硬件链路：AD9833 输出约 0.6 Vpp（固定）→ 隔直 → 放大/电平搬移 → **TP1 交流 0.5 Vrms（由 VR1 标定，直流 3.3 V）** → F+。**没有任何固件可控的幅度调节手段**（AD9833 无幅度寄存器；无 DAC/PWM/数字电位器参与激励）。因此：

- 0.5 Vrms 由硬件标定保证（生产时示波器看 TP1 调 VR1）。
- 软件把 Vin 当作“已知参考”用于比值测量；同时把 |Vin|、|Vo|、ratio、THD、削顶标志作为诊断量输出（`LVL` / `RAW` 命令），用于：
  - 台架校验激励是否在 0.5 Vrms ±10%；
  - 测量中判断激励异常（DDS 未输出、继电器未接通、通道故障）；
  - 削顶检测（ADC 码值贴边或谐波突然增大）→ 触发换档/降频重测。
- ADC 输入换算系数 `k_in`、`k_out`（代码值→rms 电压）属于**校准记录**的一部分（由台架用已知信号标定），保证 |Vin| 报告的绝对精度，但**比值 Vin/Vo 不受 k 绝对值影响**（只受两通道相对失配 α 影响），所以阻抗精度不依赖这组系数——这是架构上重要的解耦。
- 若今后硬件改版加入可编程衰减/增益，只需在 `dds` 或 `afe` 驱动增加 `set_level()`，测量内核的复数比值框架不变。

| 误差项 | 未校准量级 | 软件消除手段 | 校准后残余（目标） |
|---|---|---|---|
| ADC 量化+热噪声（12 bit、N=1024/1008、ENOB≈10.5） | 单块单通道 0.041%@0.05 Vrms（比值 ×√2=0.058%）、相位 0.012° | 相干平均 / K 块复平均（K=32） | 0.058%/√K → <0.01% |
| 两通道增益/相位失配 α | ~0.5%、~0.5° | **每频率** α 复数标定，测量时复除 | <0.05%、<0.02° |
| 夹具开路杂散（~1 pF） | 1 pF@10 pF = 10% | 开路校准（每档×每频） | <0.5% |
| 串联残差（触点+布线 ~0.1 Ω） | 0.1 Ω@10 Ω = 1% | **双负载两点法求 Zs**（本硬件无短路校准，§7.4.1） | <0.1% |
| Rf 实际值（0.1% 金属膜） | 0.1% | 双负载校准（k 吸收）＋每档真实 Rf 存表 | <0.02% |
| Rf 并联寄生 C_f | 100 kΩ/1 pF @100 kHz：0.20%、3.6° | 负载校准吸收；或按 C_f 解析修正 | <0.05%（D 指标另论） |
| 运放有限 GBW 相位误差 | OPA2810 GBW 70/105 MHz：ρ=1 时 **0.164°/0.109°**，ρ=1.59 时 **0.26°/0.17°** | 相位项并入负载校准模型；D/Q 精度单独限幅 | 幅度二阶（≤4×10⁻⁶）；相位 0.16–0.26° 由 k 吸收 |
| 继电器触点电阻漂移 | ~0.05 Ω | 测量前开路+双负载复测（可选）、结果带健康度标志 | 警告级 |
| VREF_AFE 抖动（去耦不足） | 100 kHz 下随机 | ≥3 块复数平均 + 中值 + 离散度检查 | 按块间离散度剔除 |

**推论（架构层面的两个硬决定）**：
1. **每条测量结果都必须携带“本次使用的校准项版本”**；没有校准数据时软件必须显式提示“未校准”并把误差放大系数写进结果（不能假装 1% 精度）。
2. **α 必须按频率标定**（4 个频点各一组），**开路 + 双负载必须按 (频率,档位) 标定**（4×6 组；短路校准在本硬件不可执行，见 §7.4.1），**Rf 实际值按档标定**（6 组）。

|---|---|---|---|---|

```
└─────────────────────────────────────────────────────────────────────────────────┘
```

**依赖规则（代码评审硬性检查项）**

1. 只允许上层调用下层；L1 不得 include `meas.h`/`cal.h`；L2 不得直接写寄存器（统一走 L1 API）。
2. 中断服务程序只做“搬运 + 置标志 + 计数”，不调用 `printf`、不做浮点、不操作继电器。
3. 任何模块不得 `malloc`；全部静态分配。所有对外返回的错误码统一 `int`/枚举，禁止用全局 errno 风格隐式状态。
4. 硬件相关常量只在 `board_config.h` 一个头文件中定义（引脚、时钟、档位表、频率表、Flash 地址），上层引用宏，不重复写数字。
5. 测量结果的“可信度”是结果结构体的必填字段（校准等级 + 块间离散度 + 诊断码），不允许只返回一个数值。

### 3.5 一次测量的数据流（端到端）

```
[选择 f / 档位] → relay_select_range() → 15 ms 稳定
        ↓  dds_set_freq_hz(f) → 等 1 ms（DDS 相位连续，无需复位）
adc_acquire(cfg, block)  ── TIM2 TRGO 以 fs=S·f0 触发；DMA 写 cdr[N]
        ↓  阻塞至 N 个样本完成（100 kHz: 0.84 ms；100 Hz: 640 ms）
dsp_analyze(block)      ── ① 减均值去 DC（每通道）② 按 P=S 折叠累加（int32）
                           ③ P 点复 DFT → h[1..P-1]；④ 削顶/谐波/质量指标
        ↓
dsp_combine(K blocks)   ── 复数相干平均（各块起始相位相同，合法）→ V1,V2, spread
        ↓
ratio = V1/V2；ratio /= α(f)          （α 来自 cal_record）
Zm = −Zf(f) · ratio                   （Zf = Rf 实际值；高频含 Rf∥Cf）
Zx = cal_apply_impedance(Zm)          （开路 + 双负载两点法反解）
        ↓
results: Rs/Xs → D/Q/Cs/Ls/Rp/Cp → type 判定 → 单位与有效位
        ↓
UI / 串口 / 日志
```

**为什么“复数比值”而不是“先各自取幅度”：** 两通道同时采样，起始相位相同；比值把绝对幅度、采样起始相位、DDS 初始相位全部约掉，只剩“通道复失配 α”与“Zf/Zx”两个物理项。α 可标定，Zf 可标定 → 精度可达到元件级。

### 3.6 中断与实时策略

| 中断源 | 优先级（NVIC） | 职责 | 时限约束 |
|---|---|---|---|
| DMA2 Stream0（ADC 半满/全满） | 1（最高） | 记录半满/全满计数、置 `dma_ready` 标志；检测异常 | 每个半缓冲周期 ≥320 µs，处理 <2 µs |
| USART1 RX | 2 | 字节入环形缓冲（256 B）、溢出计数 | <10 µs |
| SysTick（1 ms） | 3 | 毫秒计数、软件定时器到期标志、LED 心跳、IWDG 提示 | <5 µs |
| I2C1 事件/错误 | 4 | 由阻塞式 OLED 写使用，无异步回调（低优先级，避免影响测量） | 测量期间不刷屏 |

规则：测量采集期间（`adc_acquire` 阻塞）**不开任何可能长时间占用 CPU 的任务**；串口接收仍可用（只入缓冲），命令解析推迟到采集结束后执行。OLED 在采集期间只做单页局部刷新，禁止整屏刷新（整屏 I2C 400 kHz 约 25–30 ms，会干扰 100 ms 级时序预算并可被优化掉）。

### 3.7 错误处理与“不可信结果”原则

1. 所有测量结果必带 `cal_level`（0–3）与 `confidence`（0–3）；未校准或块间离散度 >0.5% 时 `confidence` 降级，串口返回 `WARN` 字段，OLED 显示“未校准/不确定”。
2. 采样异常（削顶、DMA 计数不符、ADC OVR、削波后谐波比 >5%）→ 结果作废并进入重试路径，不返回“看似正常”的数值。
3. 任何 `MEAS_ERR_*` 都要映射到用户可读消息（中文 OLED + 英文串口），并附带建议操作（如“检查夹具是否开路”“请先执行 CAL”）。
4. 看门狗只在主循环喂；采集阻塞路径内部也按段喂狗（防止 0.64 s 采集被误判）。

## 4. BSP 与驱动层设计（寄存器级）

本节给出可直接编码的关键配置。所有寄存器位定义以仓库内 `firmware/Drivers/CMSIS/Device/ST/STM32F4xx/Include/stm32f407xx.h` 为准（版本与实物 MCU 一致），不另引第三方库。

### 4.1 board.c — 时钟树、时基与板级基础设施

**时钟树目标**

| 时钟 | 频率 | 来源与配置 |
|---|---|---|
| SYSCLK | 168 MHz | HSE 8 MHz → PLL：M=8（1 MHz 鉴相）、N=336、P=2 |
| AHB / HCLK | 168 MHz | HPRE=1 |
| APB1 / PCLK1 | 42 MHz | PPRE1=4（定时器 TIM2–7/12–14 = 84 MHz） |
| APB2 / PCLK2 | 84 MHz | PPRE2=2（定时器 TIM1/8–11 = 168 MHz） |
| ADC 时钟 | **21 MHz** | `ADC_CCR.ADCPRE = 01`（PCLK2/4；ADCPRE 只有 /2、/4、/6、/8，见 stm32f407xx.h:1742-1746） |
| AD9833 MCLK | 8 MHz | MCO1 = HSE（`RCC_CFGR` MCO1=0b10，MCO1PRE=/1），PA8 复用 AF0 |
| Flash 等待 | 5 WS | 168 MHz / 3.3 V 档；同时开 PRFTEN + ICEN + DCEN |

**初始化顺序（board_init）**

1. `RCC->CR |= HSEON`，等 `HSERDY`（超时 100 ms）。
   - **失败路径**：回退 HSI 16 MHz（PLL 关闭），置 `board_clock_degraded=1`，串口/OLED 明确报“时钟降级，频率指标不可保证”；不允许静默继续（否则 0.1% 频率指标与 C/L 计算全错）。
2. `RCC->PLLCFGR = PLLM(8) | PLLN(336) | PLLP(0→/2) | PLLSRC(HSE) | PLLQ(7)` → `PLLON` → 等 `PLLRDY`。
3. `FLASH->ACR = 5 WS | PRFTEN | ICEN | DCEN`（必须在切到 168 MHz 之前）。
4. `RCC->CFGR = HPRE(1) | PPRE1(4) | PPRE2(2) | SW(PLL)` → 等 `SWS` 确认。
5. `SystemCoreClockUpdate()`；`SystemCoreClock` 应为 168000000，否则断言失败。
6. `SysTick_Config(SystemCoreClock/1000)` → 1 ms 时基（`board_millis()`，uint32 回绕安全）。
7. DWT 周期计数：`CoreDebug->DEMCR |= TRCENA`，`DWT->CTRL |= CYCCNTENA` → `board_cycles()`（168 MHz 下 32 位约 25.6 s 回绕，只做差值）。
8. `board_delay_us()`：<1000 µs 用 DWT 差值自旋；≥1 ms 用 SysTick（不阻塞中断）。
9. GPIO 安全态（见 4.7）。
10. IWDG：LSI≈32 kHz，PR=/32 → 1 kHz，RLR=2000 → 2 s 超时；主循环喂狗，采集过程中按块喂狗。
11. 读 `RCC->CSR` 复位标志（IWDG/WWDG/SFT/POR/PIN/BOR）→ 清 `RMVF`，开机横幅打印。

**注意点**

- MCO1 输出必须显式打开，且 AD9833 上电后 **≥20 ms** 才能写寄存器（见 4.2）；board_init 在 PLL 切换完成后立即配置 MCO1，正好覆盖这段等待。
- 未使用的引脚一律配置为模拟模式（MODER=0b11）或输出，降低浮空输入漏电与噪声；PA13/PA14 保持 SWD。
- LED = **PC13（低电平点亮）**，1 Hz 心跳由主循环驱动（心跳停 = 主循环卡死，可作为现场诊断）。

### 4.2 dds.c — AD9833 信号源

**硬件接口**：SPI1（PA5=SCK、PA7=MOSI，AF5）、PA4=FSYNC（普通推挽输出，空闲高）、MCO1/PA8 提供 8 MHz MCLK。AD9833 **只能写不能读**，所有校验必须通过 ADC 侧完成。

**SPI1 配置**

| 项目 | 值 | 说明 |
|---|---|---|
| 主/从 | 主机 | `SPI1->CR1.MSTR=1` |
| 波特率 | 84 MHz/4 = **21 MHz** | `CR1.BR=001`；AD9833 SCLK ≤40 MHz，/2=42 MHz 超限，取 /4 留余量 |
| 帧格式 | 16 bit，MSB first | `CR1.DFF=0`、`CR1.LSBFIRST=0` |
| 时钟极性/相位 | CPOL=0，CPHA=1（模式 1） | `CR1.CPOL=0`、`CR1.CPHA=1` |
| NSS | 软件片选 | `CR1.SSM=1`、`CR1.SSI=1`（内部 NSS 恒高），FSYNC 手动拉低/拉高 |
| 其它 | `CR2.SSOE=0`；只发不收（`BIDIMODE=0`、`RXONLY=0`）；`CR1.SPE` 置 1 前先清 0 配置 | 每帧：FSYNC↓ → 写 DR → 等 TXE → 等 BSY=0 → FSYNC↑ |

**频率字**

```
FREQREG = round(f × 2^28 / 8e6) = round(f × 33.554432)
        = (uint32_t)(((uint64_t)f * 268435456ULL + 4000000ULL) / 8000000ULL)
```

| 标称 f | FREQREG | 实际输出 f_act = FREQREG·8e6/2^28 | 误差 |
|---|---|---|---|
| 100 Hz | 3355 | 99.98679 Hz | −132 ppm |
| 1 kHz | 33554 | 999.98713 Hz | −12.9 ppm |
| 10 kHz | 335544 | 9999.99046 Hz | −0.95 ppm |
| 100 kHz | 3355443 | 99999.99404 Hz | −0.06 ppm |

> 误差与晶振 ±10–30 ppm 相加，最坏 <0.02%，远小于 0.1% 指标。软件在测量时**以实际写入的频率字反算 f_act 参与 C/L 计算**，不使用标称值。

**初始化与切换序列**

```
dds_init():
  1) 配置 PA4/PA5/PA7 为 AF/输出；SPI1 上电
  2) 距上电 ≥20 ms（由 board/main 保证）
  3) 写 0x2100   // B28=1（28 位频率）、RESET=1
  4) 写 0x4000 | (FREQREG & 0x3FFF)          // 频率 LSB 14 位
  5) 写 0x8000 | ((FREQREG >> 14) & 0x3FFF)  // 频率 MSB 14 位，更新生效
  6) 写 0x2000   // B28=1、RESET=0、MODE=0、OPBITEN=0、DIV2=0 → 正弦输出
```

- `dds_set_freq_hz()`：重复第 4、5 步即可，**相位连续**（DDS 累加器不清零）。测量只关心两通道比值，起始相位不影响结果。
- `dds_hold_reset(1/0)`：写 `0x2100` / `0x2000`。**继电器切换前必须静音**（RESET=1 时输出中间电平，交流激励为 0，I-V 即使在 Rf 暂时断开也不会大电流饱和；见 4.3）。
- 幅度不可数字控制（硬件用 VR1 电位器把 TP1 校到 0.5 Vrms）。固件不提供“调幅度”的伪接口，只在自检/诊断里报告实测幅度。

### 4.3 relay.c — 量程与校准开关

**档位表（GPIO 直连 ULN2803，输出高 = 线圈通电 = 触点动作）**

| 逻辑档 | GPIO | 有效电平 | Rf（网络） | 备注 |
|---|---|---|---|---|
| `RANGE_10R` | PD0 | 高 | 10 Ω（R23） | |
| `RANGE_100R` | PD1 | 高 | 100 Ω（R25） | |
| `RANGE_1K` | PD2 | 高 | 1 kΩ（R26） | |
| `RANGE_10K` | PD3 | **低** | 10 kΩ（**位号待 BOM 核对**） | **NC 常闭**：线圈断电时接入 → 上电默认档 |
| `RANGE_100K` | PD4 | 高 | 100 kΩ（R28） | |
| `RANGE_1M` | PD5 | 高 | 1 MΩ（R29） | 100 kHz 禁用（Rf∥Cf 极点 ≈159 kHz） |
| `CAL` | PD6 | 高 | 两路 ADC 输入切到 CAL 网络 | 校准专用 |

> PCB 位号与网络名不一致（K18=K2、K28=K4、K38=K3、K48=K6、K58=K7、K68=K5、K78=K1）——**该映射无网表依据（`修改5.tel` 不在仓库），待实物/网表核对**；调试时以 GPIO 为准，位号只用于上板核对。
>
> **驱动/线圈事实（`afe.md` Q5）**：ULN2803A 低边灌电流，IN1–7 = PD0–PD6；线圈 237 Ω / 21.1 mA @5 V、动作 ≤3 ms；按脚本应有 COM(10) 接 +5 V、每只线圈并 1N4148 续流，但 **COM 接法 / 1N4148 是否贴装、以及“7 只全吸 148 mA 会拉塌 5 V”均未实测**（5 V 峰值 ~330 mA < PTC 500 mA）→ 保留“同时 ≤2 只”互锁并标注未实测。

**重要推论（与 `硬件接口.md` 的一处需要澄清之处）**

10 kΩ 档是 NC 默认档，选择**任何其它档**都必须同时让 K48 吸合以断开 10 kΩ，否则 10 kΩ 与被选 Rf 并联。因此稳态电流不是“1 只线圈”，而是 **目标档 + K48 共 2 只**（约 2×21 mA = 42 mA）。**K48 的 NC 默认接法已由 afe-hw 核对（`afe.md` Q5）确认**：COM(6)=Rf、NC(7)=Vo，线圈不吸合即 10 kΩ 在位；若实物与此不符只需改档位表，上层不受影响。

**切换协议（`relay_select_range` 的调用前置条件：DDS 已静音）**

```
① 目标=10k：PD3 已在低（NC 接通），其余档全低 → 5 ms → 10 ms
② 目标≠10k：所有非目标档引脚拉低 → 目标档引脚拉高（DDS 已静音，与 10k 短暂并联无电流）→ 10 ms
            → PD3 拉高（断开 10k）→ 5 ms
③ 返回后由调用者解除 DDS 静音并再等 1 ms 才允许采样
```

- 互斥断言：任意时刻**至多一个非 10 kΩ 档引脚为高**；若检测到非法组合立即全部拉低并报 `MEAS_ERR_RANGE`。
- 时间依据：继电器动作 ≤3 ms；新协议为“目标档吸合 10 ms → 断 K48 5 ms”（总时长与 `硬件接口.md` 的 5+10 ms 相同）；`relay_select_range()` 返回实际经过毫秒数，写入日志，供 §9 时间预算核对。
- 校准开关（K78）与量程开关独立：`relay_cal_enable(1)` 只动 PD6，不动 Rf；α 校准必须在某个有效 Rf 已接通的状态下进行。
- 触点寿命：每次切换计数，保存在 RAM 日志；不写 Flash（避免磨损与掉电风险）。

### 4.4 adc.c — 双 ADC 同步采样与 DMA

**这是全系统最关键、最容易配错的一段。**

```
PA0 = ADC1_IN0（S+ 经 RC）      PA1 = ADC2_IN1（Vo）
模式：双重规则同步（ADC1 主、ADC2 从）→ ADC->CCR.MULTI = 0b00110（REGSIMULT）
触发：TIM2 TRGO 上升沿 → ADC_CR2.EXTSEL = 0110、EXTEN = 01
       （0110 = TIM2_TRGO，与硬件接口.md 的触发编码一致；那里把定时器名写成了 TIM8，见 §1.3-M3）
采样：ADC_SMPR2.SMP0 = 000（3 个 ADC 周期）
      → 12 bit + 3 cyc = 15 个 ADC 周期 = 714 ns @21 MHz
数据：ADC->CDR 低 16 位 = ADC1(Vin)，高 16 位 = ADC2(Vo)
      （ADC_CDR_RDATA_MST=ADC_CDR_DATA1，stm32f407xx.h:1763-1764）
搬运：DMA2 Stream0 Channel0，外设→存储器，32 bit，循环模式
```

**为什么只能这样配**

- `ADC_CCR.ADCPRE` 只能 /2、/4、/6、/8 → 28 MHz 不存在，21 MHz 是唯一 ≤36 MHz 且离 28 MHz 最近的选择（`硬件接口.md` 的 28 MHz 作废，见 §1.3-M1）。
- 15 周期/次 = 714 ns → 单 ADC 理论最高 ≈1.4 MSPS。因此 `fs=16f0` 在 100 kHz（需 1.6 MSPS）**不可行**，100 kHz 用 `S=12`（fs=1.2 MSPS，仍 ≤1.4 MSPS 上限；见 §1.3-M2、§5.1）。
- 双 ADC 同步模式下，**只能读 ADC->CDR**（一次 32 位读拿到两路，保证同一触发沿）；逐个读 ADC1->DR / ADC2->DR 无法保证同一样本对。
- DMA 必须循环 + 双缓冲（半满/全满），禁止在触发中断里搬数据。

**TIM2 配置（fs = 84 MHz/(ARR+1)，32 位计数器，PSC=0）**

| f0 | S=fs/f0 | fs | ARR | 每块时间 |
|---|---|---|---|---|
| 100 Hz | 16 | 1.600 kHz | 52 499 | 0.64 s |
| 1 kHz | 16 | 16.0 kHz | 5 249 | 64 ms |
| 10 kHz | 16 | 160 kHz | 524 | 6.4 ms |
| 100 kHz | 12 | 1.2 MHz | 69 | 0.84 ms（N=1008） |

- `TIM2->PSC=0`、`TIM2->ARR` 如上（`ARR+1` = 52500/5250/525/70，全部整除：84e6/1600=52500、/16000=5250、/160000=525、/1 200 000=70）；`TIM2->CR2.MMS=010`（update 事件作 TRGO，MMS_1=0x20）；`TIM2->EGR.UG=1` 预装载；`TIM2->CR1.CEN=1` 启动。
- **为什么不用 TIM8**：TIM8 是 **16 位**计数器，100 Hz 档 `ARR+1 = 168e6/1600 = 105000 > 65535`，`硬件接口.md` 的“TIM8、ARR=104999”按字面写不进去；若坚持 TIM8 必须 `PSC=1`（等效 84 MHz，ARR=52499）。TIM2 是 32 位、PSC=0 直接装 52500，且 **EXTSEL=0110 正是 TIM2_TRGO**——只改定时器名，不改触发编码。
- 软件反算实际采样率：`fs_hz = 84000000/(ARR+1)`，`f0_hz = fs_hz/S`；C/L 换算用 AD9833 侧实际频率 `f_dds`（见 §5.2、§6.6）。

**DMA 配置**

```
DMA2_Stream0->PAR   = (uint32_t)&ADC->CDR
DMA2_Stream0->M0AR  = (uint32_t)adc_dma_buf        // 2×N 个 uint32_t = 8 KB
DMA2_Stream0->NDTR  = 2*N
CR: CHSEL=0, DIR=01, MSIZE=10(32bit), PSIZE=10(32bit), MINC=1,
    CIRC=1, HTIE=1, TCIE=1, PL=01(medium), EN=1
NVIC: DMA2_Stream0_IRQn 优先级 1
```

- 公共寄存器：`ADC->CCR = MULTI_2|MULTI_1`（常规同步）、`ADCPRE_0`（/4=21 MHz）、`DMA_1`（DMA mode 2：CDR 双半字成对打包，`hal_adc_ex.h:156-159` 的 `ADC_DMAACCESSMODE_2`）；**从 ADC 的 `CR2.DMA` 保持 0**。
- 缓冲 `static uint32_t adc_dma_buf[2*ADC_N_MAX] __attribute__((section(".dma_buf"), aligned(32)))`；**必须放 SRAM，不能放 CCM**（F4 的 DMA 不能访问 CCM RAM）；链接脚本需加 `.dma_buf` 段并保证不被 gc。
- 半满/全满中断各对应一块；ISR 只做：块计数 +1、置 `block_ready`、检查 `ADC1->SR.OVR`/`ADC2->SR.OVR`（位 5，stm32f407xx.h:1193-1195）与 `DMA2_Stream0->NDTR==0` 异常。
- 采集 N 块后：`TIM2->CR1.CEN=0`、`ADC1->CR2.ADON=0`、`ADC2->CR2.ADON=0`、关 DMA 流；下次采集重新 NDTR + 使能。
- 出现 OVR：该块作废，重新初始化 ADC（写 SR 清 OVR 后需重新使能），计错误码；连续 3 次 OVR → `MEAS_ERR_TIMEOUT`。

**模拟看门狗（AWD）——10 Ω 档削顶的硬件级保护（新增）**

- 仅在 `10 Ω` 档精测启用（Rf=10 Ω、ρ≈1.59、L=10 µH@100 kHz 等最坏点）：`ADC1/ADC2->CR1.AWDEN=1`（规则通道），`HTR/LTR = 2048±1490`（≈1.65 V±1.2 V，即码值 558/3538，同时留 ADC 摆幅与 BUF634A headroom 余量）；
- `CR1.AWDIE=1`，AWD 中断优先级高于 DMA（设 0）；ISR 内只做三件事：`dds_hold_reset(1)` 静音 → 停 `TIM2`/DMA（`CR1.CEN=0`、`DMA2_Stream0->CR.EN=0`）→ 置 `MEAS_ERR_CLIP` 事件；
- 响应 = 1 个采样周期（100 kHz S=12 时 0.83 µs）+ 中断延迟（~0.1–0.2 µs）→ **<10 µs**，在 I-V 缓冲被削顶/过流累积之前切断；DUT 短路、错档、接触瞬间都不会烧 Rf；
- 与软件路径的关系：AWD 是**最后一道保险**；`clip` 计数与 `ρ` 越界仍是第一道（采样后判据），AWD 触发后必须重走 `relay_select_range` 降档并重测，不直接给读数；
- 只有 10 Ω 档开 AWD（其它档 `HTR/LTR` 覆盖全量程，开着无意义且可能误报）；`AWDEN` 在 `adc_acquire()` 前按档位设置，块结束清零。

**上电校准的结论（重要）**

本仓库 CMSIS 头 `stm32f407xx.h` 的 ADC_CR2 只有 ADON(0)、CONT(1)、DMA(8)、DDS(9)、EOCS(10)、ALIGN(11)、JEXTSEL(16-19)、JEXTEN(20-21)、JSWSTART(22)、EXTSEL(24-27)、EXTEN(28-29)、SWSTART(30) —— **没有 CAL/RSTCAL 位**，本仓库 HAL 也没有 Calibration 函数（`stm32f4xx_hal_adc_ex.h` 只有注入组与多模式 DMA 接口）。即 **STM32F4 的 ADC 没有软件自校准流程**，靠出厂修调；上电只需 `ADON=1` 后等待 tSTAB（参考 HAL 的 `ADC_STAB_DELAY_US`，约 3 µs 量级）再启动。文档不再声称需要“ADC 自校准”。

### 4.5 uart.c — 串口（在现有骨架上加固，TX 非阻塞）

- USART1（APB2 84 MHz）：`BRR = 45.5625`（Mantissa=45、Fraction=9，实际 84e6/729 = 115 226 bps，误差 +0.02%）；8N1，`UE|TE|RE`，RXNEIE 开中断。
- 现有骨架已具备：`uart_init/uart_write/uart_printf/uart_available/uart_read_byte`，**RX 已有 256 B 环形缓冲**（`head/tail`、`USART1_IRQHandler` 读 DR 清 RXNE/ORE、满则丢字节）。本阶段只补：`rx_overflow` 计数、`uart_rx_flush()`、`uart_rx_overflow()`。
- **TX 非阻塞**：512 B 环形缓冲 + TXE 中断；`uart_write()` 只把数据放进环（满则返回 0 或部分写入），`_write()` 直通 TX 环；`uart_write_blocking()` 仅供启动横幅/停机诊断。删除旧骨架“轮询 TXE 阻塞发送”的实现。
- `printf` 重定向到 `_write`（nano.specs）；**故意不开 `-u_printf_float`**，浮点结果由 `results.c` 定点化输出（§8.4）。
- 命令行长缓冲 96 B，主循环 `proto_poll()` 取行；采集阻塞期间**只入缓冲、不解析**（RX 环 256 B 在 115200 下约 22 ms 输入量，见 §8.5 协议规则）。
- `RAW ON`：**快照模式**（采 1 块 → 停采 → 输出 → 自动 `RAW OFF`），二进制帧格式见 §8.5，避免 ASCII 大流量拖慢主循环。
### 4.6 i2c_oled.c — OLED 显示

### 4.7 上电初始化顺序与安全态

```
上电/复位
  ├─ 硬件复位态（MCU 引脚高阻；ULN2803 输入无外部下拉 ⇒ 复位窗口内线圈可能误吸合，见 §12-R3/D16）

  ├─ board_init: HSE/PLL 168 MHz → Flash 5WS → SysTick → DWT → GPIO 安全态 → IWDG
  ├─ uart_init(115200)（先让调试口可用，后续步骤都能报错）
  ├─ 延时补足 AD9833 ≥20 ms 上电时间
  ├─ dds_init: SPI1 → 0x2100 → 频率字 → 0x2000  （此时已有 10 kΩ Rf）
  ├─ relay_init: 全部拉低（保持 10 kΩ 默认档），CAL 关
  ├─ adc_init: GPIO 模拟 → 双 ADC 同步 + TIM2 + DMA2S0 配置好但不启动
  ├─ i2c_oled_init: 探测 + 清屏（失败降级）
  ├─ cal_init: 从 Flash 校准区（sector6/sector7 双扇区）扫描记录、CRC 校验、置 cal_level
  ├─ selftest_run: 时钟/串口/DDS(经 ADC 观测)/ADC 通道/继电器/校准数据检查
  └─ 主循环: proto_poll + 事件分发 + ui_poll + 看门狗
```

- 初始化总耗时目标 <350 ms（其中 AD9833 等待 20 ms、OLED 初始化 ≤60 ms 为固定开销）。
- 任何一步失败都写入 `boot_status` 位掩码，串口横幅打印；致命失败（时钟）仍允许串口交互以便诊断，但拒绝给出测量值。

## 5. 采样与相敏检测（DFT 内核）

### 5.1 相干采样参数总表

全部参数满足“采样窗口内整数个信号周期”，这是矩形窗 DFT 无泄漏的前提。`S = fs/f0` 为每周期采样点数，`N` 为每块样本数，`M = N/S` 为窗口内周期数。采样由 **TIM2**（APB1 定时器 84 MHz、32 位、PSC=0）经 TRGO 触发。

| 场景 | f0 | S | fs = S·f0 | TIM2 ARR | N | M | 单块时间 | 块数 K | 该频点总采集 |
|---|---|---|---|---|---|---|---|---|---|
| 100 Hz 粗测 | 100 Hz | 16 | 1.600 kHz | 52 499 | **64** | 4 | 40 ms | 1 | 40 ms |
| 100 Hz 精测 | 100 Hz | 16 | 1.600 kHz | 52 499 | 1024 | 64 | 640 ms | 1 | 640 ms |
| 1 kHz 粗/精 | 1 kHz | 16 | 16.0 kHz | 5 249 | 64/1024 | 4/64 | 4/64 ms | 1/8 | 4/512 ms |
| 10 kHz 粗/精 | 10 kHz | 16 | 160 kHz | 524 | 64/1024 | 4/64 | 0.4/6.4 ms | 1/16 | 0.4/102.4 ms |
| 100 kHz 粗/精 | 100 kHz | **12** | 1.2 MHz | **69** | 96/1008 | 8/84 | 0.08/0.84 ms | 1/32 | 0.08/26.88 ms |

- ARR 计算：`ARR = 84 000 000/(S·f0) − 1`，四档全部是精确整数（84e6/1600=52500、/16000=5250、/160000=525、/1 200 000=70；fs 精确，定时器误差 0）。
- **100 Hz 是硬约束**：N=1024 单块 640 ms，1 s 内最多 1 块（2 块 1516 ms 超时）⇒ **粗测一律 N≤128（推荐 64）**、100 Hz 精测 K=1；最长路径（100 Hz + 自动量程 + 1 MΩ 档）约 **877 ms**，其余频点 worst 605/181/105 ms（§9）。
- 100 kHz 的 `S=12` 是物理约束下的最优整数（ADC 21 MHz 下单次转换 714 ns ⇒ 上限 1.4 MSPS；1.6 MSPS 不可行、S=8 虽可行但 7f/9f 折回基波污染 ~0.86%，见 §1.3-M2/§5.6）：每周期 12 点、fs=1.2 MSPS、M=84；12 点 DFT 可算 h=1…11，但质量判据只用 h2（200 kHz 干净），h3 会被 9f=900 kHz 混叠污染（仅参考）。
- 块数 K 是**默认平均块数**：1 kHz 取 8（R 发挥项 0.5% 需 3σ≤0.1%；0.05 Vrms 下 K=8 的 3σ≈0.087%）、10 kHz 取 16、100 kHz 取 32（主要压 VREF_AFE 抖动）；C/L 基础指标（2%）单块 3σ 已足够，`meas.c` 按类型/目标精度动态削减（§9.3）。

### 5.2 采样率、信号频率与相干性误差

信号来自 AD9833（`f_dds = F·8e6/2^28`，F 为整数频率字），采样率来自 TIM2（`fs = 84e6/(ARR+1)`），两者都由 HSE 派生但无法同时精确整数化：

```
实际周期数      M_act = N·f_dds/fs
与设计 M 的偏差 δ = M_act − M   （单位：bin）
例：100 Hz，N=1024，f_dds=99.986792 Hz，fs=1600 → M_act = 63.99155 → δ = −0.00845 bin
```

- **偏差量级 0.008 bin，对本系统无实质影响**：两通道在同一个窗口内同步采样，δ 造成的幅度/相位泄漏在比值 Vin/Vo 中一阶抵消，残余 ≤1.3×10⁻² % 幅度、≤0.0074° 相位。
- 因此**不加窗（矩形窗）**、**不微调 ARR**；只要 `|δ| < 0.02 bin` 就认为相干条件成立。
- 强制检查：`|δ| < 0.02` 否则置 `confidence` 降级并记录（时钟降级/ARR 配置错误时会触发）。
- C/L 换算必须使用 **f_dds 实际频率**（误差 −132 ppm @100 Hz），不得用标称 100/1k/10k/100k。
- 100 kHz（S=12）实例：f_dds=99.999994 kHz（频率字 3 355 443，−0.06 ppm）、fs=1.2 MSPS、N=1008 → M_act=83.999995、**δ≈−5×10⁻⁶ bin**，相干性远优于 0.02 判据。

### 5.3 16/12 相折叠：把 N 点 DFT 降成 N 次整数加法

**推导**（设 `N = S·M`，目标 bin 为 `k0 = h·M`，即 h 次谐波）：

```
x[n] = A·cos(2π·h·M·n/N + φ)
把 n 写成 n = p + S·k，p∈[0,S)，k∈[0,M)：
  2π·h·M·(p+Sk)/(S·M) = 2π·h·p/S + 2π·h·k  ⇒  e^{-j2πhM n/N} = e^{-j2πh p/S}
X_h = Σ_{p=0}^{S-1} e^{-j2πh p/S} · A_p ,   A_p = Σ_{k=0}^{M-1} x[p + S·k]
```

**结论：先把样本按“落在周期内第几点”折叠成 S 个整数累加器 `A_p`（每样本 1 次加法），再对 S 个累加器做一次 S 点 DFT，就能同时得到 1…S−1 次谐波。** 对基波（h=1）只需 S=16（或 S=12）点 DFT；对 100 kHz（S=12）可算 h=1…11（实际只用 h1/h2，h3 受 9f 混叠污染）。

```
for (n = 0; n < N; n++) {
    uint32_t w = cdr[n];
    int32_t  v1 = (int32_t)(w & 0xFFFF) - dc1;      // Vin
    int32_t  v2 = (int32_t)(w >> 16)    - dc2;      // Vo
    a1[n % S] += v1;        a2[n % S] += v2;        // S=16/12：% 由常量折叠；或相位计数器循环
}
/* S 点复 DFT，同时算 Vin / Vo */
for (h = 1; h < S; h++) {
    float re1=0, im1=0, re2=0, im2=0;
    for (p = 0; p < S; p++) {
        unsigned idx = (unsigned)(h * p) % S;      // S=12 非 2 的幂，用取模（常量折叠）
        float c = cos_tab[idx], s = sin_tab[idx];
        re1 += a1[p]*c;  im1 -= a1[p]*s;
        re2 += a2[p]*c;  im2 -= a2[p]*s;
    }
    X1[h] = C(re1, im1);  X2[h] = C(re2, im2);
}
```

**成本**：`N` 次整数加法 + 2×(S−1) 次 S 点 DFT。100 kHz、N=1008 时约 2016 次“读 CDR + 减法 + 加法”，在 168 MHz、开 FPU 下估计 **0.1–0.2 ms**（budget 任务会给出实测数），相对 0.84 ms 的采集时间可忽略。

**实现细节**

- `S` 只取 16 或 12；16 可用 `n & 15` 免除法，12 用取模（常量折叠成乘加）或“相位计数器 + 归零”，避免运行时除法。
- `dc1/dc2` 为每块均值（码值）：先扫一遍求均值，第二遍折叠时减去。均值是常量时对 bin 0 之外的 bin 没有贡献，减掉只是为了抑制块内漂移与温度慢变。
- 相位表 `cos_tab`：S=16 用 `cos(πp/8)`（16 值只需 8 个 + 符号）；S=12 用 `cos(πp/6) = {1, 0.866025, 0.5, 0, −0.5, −0.866025, −1, −0.866025, −0.5, 0, 0.5, 0.866025}`，`sin_tab` 为 `sin(πp/6)` 同 12 值；放 CCM 或 const；
- 折叠只处理与 `S` 对齐的 bin（`k0 = h·M`），恰好覆盖我们要的全部谐波；其它频率成分（噪声、杂散）自然分摊到 S 个相位上并在 DFT 中被抑制——这正是相干 DFT 的窄带滤波作用。

### 5.4 归一化与相位定义（全工程唯一定义，禁止各处换算）

```
X = Σ x[n]·e^{-j2πk0 n/N} = (A_peak·N/2)·e^{jφ}
⇒ 峰值 A_peak = 2·|X|/N      （码值）
⇒ 有效值 A_rms = √2·|X|/N     （码值，= A_peak/√2）
⇒ 相位 φ = atan2(Im X, Re X)  （rad，单位：信号相对“采样起点”的初相）
```

- 全工程只使用**峰值幅度**做比值（`ratio = V1_peak/V2_peak`，比值与归一化因子无关）；只在显示/诊断时换算 rms。
- 电压换算：`V_rms = A_rms × LSB × (1/k)`，其中 LSB=3.3 V/4096=0.8057 mV，k 为前端交流耦合+偏置网络的传递系数（由负载校准得到，见 §7）。**电压换算不影响主测量结果**，只用于 OLED 显示与诊断。
- **相位一律由复数除法直接得到**（`Zx = −Zf_eff·(m1/m2)/α` 后取 `atan2(Im, Re)`），角度只在显示时换算；不要手算 `φ_Z` 的三角关系（α 符号、180°、arg Zf_eff 三项都容易漏），完整公式见 §6.2。

### 5.5 多块平均：必须“按块算比值，再平均比值”

这是容易写错、且错了不会报错的地方：

- **块间相位关系取决于 DMA 是否连续**：本实现用循环 DMA 连续采样（§5.7），TIM2 不归零、DDS 累加器自由运行，每块起点相位推进 `2π·M_act ≈ 2π`（整数周期）⇒ 块间绝对相位几乎确定，**并非随机**；若将来改成逐块重启 TIM2，则相位随机。
- 因此**不要**先把各块的 `V1`、`V2` 复数分别累加再相除：连续 DMA 下数学上可行，但一旦块边界/重启/换频导致相位跳变就会静默出错；逐块算比值对两种设计都安全，是统一做法。
- 正确做法：**每块独立计算复比值 `R_b = V1_b/V2_b`**，再把 `R_b` 复平均：

```
R̄ = (1/K)·Σ R_b                     // 复数平均；K 块时间上连续
spread_lin = std(|R_b|)/|R̄|          // 相对离散度
spread_ph  = max|arg(R_b) − arg(R̄)|  // 相位离散度（度）
```

- 判定：`K≥2` 且 `spread_lin > 0.5%` → 结果降级（WARN）；`>2%` → 失败（环境干扰/接触不良）。
- 100 Hz 精测 K=1（时间限制），此时 reliability 只能靠 α 的标定新鲜度和削顶/谐波指标；这也是 100 Hz 需要“粗测+精测”两遍的原因之一：粗测已给出量级，精测单块可接受。
- **注意**：K 块平均只能压噪声/漂移，**确定性偏置（混叠谐波、通道非线性）不会被削弱**——100 kHz 在 S=8 时曾让 7f/9f 折回基波形成 ~0.86% 偏置，改用 S=12 后该偏置消失（§5.6），这就是“选对 S 比多平均更有效”的例子。

### 5.6 质量指标与 100 kHz 的“8 点/周期”限制

每块除基波外还输出：

| 指标 | 定义 | 用途 | 判定阈值（建议） |
|---|---|---|---|
| `dc1/dc2` | 码值均值 | 前端偏置检查 | 偏离 2048±80 → WARN |
| `clip` | 码值 ≤3 或 ≥4092 的样本数 | 削顶/钳位 | >0 → 该块作废 |
| `h2` | `\|X_2\|/\|X_1\|`（Vin 与 Vo 各算） | 前端非线性/削顶 | Vin 侧 >0.5% → WARN；DDS 本底约 −50 dBc（0.3%）会贴线，判定优先用 Vin/Vo 两通道 h2 之差 |
| `h3` | `\|X_3\|/\|X_1\|` | 仅 S=16 可用 | S=12 时被 9f=900 kHz 混叠污染 → 仅参考、不作判据（见下） |
| `rss` | `sqrt(Σ(x[n]−拟合基波)²)/N / A_peak` | 残余噪声 | >0.5% → WARN |

**S=12 的混叠约束（100 kHz 专用）**：fs=1.2 MHz，Nyquist=600 kHz。DDS 谐波 2f=200 kHz→h2、3f=300 kHz→h3、4f=400 kHz→h4、5f=500 kHz→h5 全部干净可测；6f=600 kHz 恰在 Nyquist 边缘（忽略）；**7f=700 kHz→500 kHz(h5)**、8f=800 kHz→400 kHz(h4)、9f=900 kHz→300 kHz(h3)，11f=1.1 MHz 才折回 100 kHz(h1)。结论：**基波 bin 干净**（S=8 时 7f/9f 折回基波、估算 ~0.86% 的偏置已消除，2% 指标下无需为此加预算）；h2 是干净的非线性/削顶指标，h3 仅作参考（被 9f 污染）；削顶仍以 `clip` 计数 + `dc` 偏移 + AWD（§4.4）为准。

### 5.7 数值精度与实现选择

- 折叠累加：`int32_t a[16]`（S 最大 16），上界 `M·4095`：M 最大 84（100 kHz）→ **343 980**，远小于 2³¹；无溢出风险。
- S 点 DFT：`int32 → float` 后单精度计算，多组 (S−1)×S×2 次乘加（S≤16）；单精度相对误差 ~10⁻⁷，远低于 0.01% 需求；无需双精度（双精度在 M4F 上是软件模拟，慢 10–20×）。
- 相位表与所有常量放 `.rodata`/CCM；热循环（折叠）只读写 SRAM/CCM，不与 DMA 争用。
- `cdr[]` 缓冲由 DMA 写、CPU 读：同一块只在一半/全满中断后读取，另一半 DMA 正在写 → **无竞态**（这也是必须用双缓冲的原因）。

### 5.8 与历史文档的差异

| 项 | 旧文档（part1–6 / numbers.md） | 本架构 | 原因 |
|---|---|---|---|
| 100 kHz 采样 | fs=16f0=1.6 MSPS | **S=12, fs=1.2 MHz（N=1008）** | ADC 21 MHz 上限 + 避开 7f/9f 折回基波 |
| 谐波利用 | 未提 | 折叠免费得到 1–7 次（S=16）/1–11 次（S=12，h3 受 9f 混叠） | 算法副产品 |
| 噪声带宽 | f0/64=1.56 kHz@100k | **ENBW=fs/N=f0/M=1190 Hz@100k** | S=12/N=1008，ENBW 更低 |
| 加窗 | “可选 Hann” | **不加窗** | 相干采样，矩形窗最优 |
| 100 Hz 时序 | 单遍 640 ms、两遍 1.28 s | 粗 64→40 ms，精 1024→640 ms（合计 877 ms） | ≤1 s 硬指标 |
| 归一化 | 2\|X\|/N 与 1/2 混用 | 峰值=2\|X\|/N、rms=√2\|X\|/N 唯一定义 | 避免差 2 倍错误 |

```
        ┌─────────────────────────────────────────────┐
        │ S4 结算：Zx → Rs/Xs → D/Q → Cs/Ls/Rs         │
        │    类型确认/翻转 + 置信度 + 诊断码            │
        └──────┬──────────────────────────────────────┘
               ▼
        ┌─────────────────────────────────────────────┐
        │ S5 若类型置信度低：换第二频率复核斜率（6.5），  │
        │    仍不确定则报“类型不确定”但仍给最可能值     │
        └─────────────────────────────────────────────┘
```

- 每个状态都输出结构化中间结果，写入 `meas_trace_t`（档位序列、频率序列、ρ、削顶次数、耗时），串口 `T` 命令可直接打印，用于台架定位。
- 任何一步失败都必须能回答“是开路、短路、超量程、削顶、校准缺失、信号异常还是时序超时”（见 6.8 诊断码）。

### 6.2 复阻抗计算：母公式与符号约定（定稿）

硬件模拟链（afe-hw 逆向结论）：

```
AD9833 → C1 → R1 → OPA2810 反相放大 → BUF634A → TP1 = F+
F+ ─── DUT ─── F− ──[SUM 虚地]── OPA2810 I-V ── BUF634A ── VO
S+ = DUT 高端真实电压（消 F+ 引线压降）→ CH1(Vin)
VO → CH2(Vo)
VREF_AFE = 3.300 V 为整条链的虚地/参考
```

**母公式**（全程交流量，VREF 已由前端交流耦合与 DFT 去均值消去）：

```
Vo/Vin = −Zf_eff/Zx
⇒  Zx = −Zf_eff · (Vin/Vo)

其中把两路 DFT 结果记为 m1（CH1=Vin）、m2（CH2=Vo）
真实比值  R = V1/V2 = (m1/m2)/α(f)
⇒  Zx = −Zf_eff(f) · (m1/m2) / α(f)
```

| 符号 | 定义 | 来源 |
|---|---|---|
| `m1, m2` | 两路通道的复 DFT 基波值（峰值，码值） | `dsp_analyze` |
| `α(f)` | 两路调理链复增益比 `g1/g2`，在 CAL 通道短接时测得 `α = m1/m2`（此时两路输入同一 CAL 源） | §7.2 |
| `Zf_eff(f)` | 反馈阻抗实际值：`Rf/(1+j2πf·Rf·Cf)`，含每档并联补偿电容；10 kΩ 档 `Rf` 的实际值由负载校准给出 | §6.2、§7.4 |
| `R` | 复比值 `(m1/m2)/α`，即 `Vin_ac/Vo_ac` | 本模块 |

> **口径定稿（与 `硬件接口.md` L19/L208、`fig13` 的差异）**：因为 `α = m1/m2 = g1/g2`，若写成 `Zx = −Zf·α·(Vin/Vo)` 会差 `α²`（约 1% 量级，直接吃掉指标）。**固件统一为 `Zx = −Zf_eff·(m1/m2)/α`，即“比值再除以 α”。** 文档与代码注释均以此为准；串口返回的 `alpha=` 字段打印 α 本身，便于复核。

- 负号不能丢：它决定 `φ_Z` 的符号，进而决定 C/L 判别。
- `Vin/Vo` 是复数比值：`|Zx| = |Zf_eff|·|m1/m2|/|α|`，`φ_Z = arg(m1/m2) − arg(α) − arg(Zf_eff) + 180°`（与实现相统一：实现直接做复数除法，不手算角度）。
- 两路通道的绝对相位在块间随机（§5.5），但**比值相位稳定**；α 只与通道匹配和频率有关。

### 6.3 自动选频

**选频规则**（先用 1 kHz 粗测拿到 `|Z_rough|` 与 `φ_rough`，再按目标类型选）：

| 目标类型 | 频率选择 | 理由 |
|---|---|---|
| R | 固定 **1 kHz**（除非 1 MΩ 档需降到 100 Hz/1 kHz） | 电阻无频率依赖；1 kHz 下开路/双负载残差影响小 |
| C | 在“档位-频率合法表”内取 **最高可用频率** | `\|Z\|=1/(2πfC)`，高频把 \|Z\| 拉进最优窗口；同时减小夹具并联杂散影响的时间常数 |
| L | 取 **最低可用频率** | `\|Z\|=2πfL`，低频把 \|Z\| 拉进窗口；100 mH 在 100 Hz 时 \|Z\|=62.8 Ω 正好 |
| 未知 | 先按 R 处理，再按 φ 判据复核；仍不确定则双频复核（6.5） | 避免错误选频放大误差 |

**档位-频率合法表**（决定“这个档位能不能在这个频率用”）：

| 档位 \ 频率 | 100 Hz | 1 kHz | 10 kHz | 100 kHz |
|---|---|---|---|---|
| 10 Ω | ✓ | ✓ | ✓ | ✓ |
| 100 Ω | ✓ | ✓ | ✓ | ✓ |
| 1 kΩ | ✓ | ✓ | ✓ | ✓ |
| 10 kΩ | ✓ | ✓ | ✓ | ✓（Cf 小，可接受） |
| 100 kΩ | ✓ | ✓ | ✓ | **△ 仅校准后**（Rf∥Cf 在 2.2 pF 时 −0.94%/相位 7.87°） |
| 1 MΩ | ✓ | ✓ | △ 仅校准后 | **✗ 禁止**（极点 ≈159 kHz，100 kHz 时 −15.3%/+32.1°） |

- 表由 `board_config.h` 的 `range_freq_legal[6][4]` 表驱动；自动量程只能落在合法组合上，非法组合直接排除并记录。

### 6.4 自动量程

核心变量 `ρ = Rf/|Zx|`（＝期望的 `|Vo|/|Vin|`）。目标：`ρ ≈ 0.3`（对应最佳信噪比与最宽校准裕量）。

**ρ_max 按档（不能一刀切 2.0）**：

| 档位 | ρ_max（典型件） | ρ_max（最坏件） | 约束来源 |
|---|---|---|---|
| 10 Ω | **1.4** | 1.25 | BUF634A 低侧 headroom：ρ=2.0 → I_pk=141 mA → 可用峰仅 1.14/0.86 V < 需 1.414 V（10 µH@100 kHz 的 1.59 只在典型件成立） |
| 100 Ω–1 MΩ | **2.0** | 2.0 | ADC 前端 Vo≤1.166 Vrms（\|Vin\|=0.5 Vrms → 2.33；\|Vin\| 上浮 10% 时 2.12） |
| 全局硬限 | — | 2.2 | 旧值，仅在 AWD 未触发且实测无削顶时允许单点例外 |

| 条件 | 动作 |
|---|---|
| `ρ > ρ_max(档)` 或检测到削顶/AWD 越界 | **降一档**（Rf 变小）——`\|Vo\|` 过大，ADC/I-V 已贴边 |
| `ρ < 0.12` | **升一档**（Rf 变大）——`\|Vo\|` 太小，量化/噪声占比高 |
| `0.12 ≤ ρ ≤ ρ_max(档)` | 接受；其中 `0.2–0.8` 记为 `MARGIN_GOOD`，`0.12–0.2`/`0.8–ρ_max` 记 `MARGIN_MID/LOW` |
| 尝试 3 次仍不满足 | 返回 `MEAS_ERR_RANGE`，保留最接近 `ρ=0.3` 的一次测量并附诊断码 |
| 首次即为 10 kΩ（NC 默认档），跳档需切继电器 | 切换前 DDS 静音（§4.3），切换后 ≥15 ms 再采样 |

**边界与安全**

- `ρ` 物理上限由两级决定：① **ADC 前端** `|Vo| ≤ 1.166 Vrms`（3.3 Vpp，由 BAT54S 钳位 −0.3～+3.6 V 与 OPA2320 RRIO 摆幅决定）；② **I-V 缓冲低侧 headroom 更严**（BUF634A 9 V 供电：±10 mA 时 1.6/1.8 V、±100 mA 时 2.0/2.2 V → 可用峰 1.5–1.7 V / 0.8–1.1 V）。**因此 ρ_max 必须按档：10 Ω 档 1.4（最坏件 1.25）、100 Ω–1 MΩ 档 2.0**；`L=10 µH@100 kHz` 的 `ρ=1.59` **不再视为“合法”，而是“仅典型件可行”**（最坏件 −0.13 V）→ 必须 M1 实测 U16/BUF634A 80 mA rms 摆幅与 R23 温升通过，并全程 AWD 监控；不通过则报 `HEADROOM`（ERR 10）并建议改测 100 µH 以上。
- **保护策略（定稿）**：真短路禁止（`CAL S` 不提供）；**10 Ω 档精测强制开启 ADC 模拟看门狗（AWD）**，阈值取 [Δ/2, 4095−Δ]（Δ 按 0.9×最小可用摆幅），越界 → 立即 `dds_hold_reset(1)` + 停 DMA，响应要求 **<10 µs**；随后降档重试，仍越界返回 `SHORT`（短路按**不可恢复事件**记录，不做短路校准）。任何档位的 AWD 越界/削顶都必须先静音再切换。
- 10 Ω 档的“可测下限”是 10 Ω（`ρ=1`）；更小的 R 只做 AWD 兜底的“疑似短路”判定并报错，不做直接测量（不提供短接校准工装，§7.4）。
- **无档可退**：已到最小档（10 Ω）且 AWD 仍越界/削顶 → 返回 `HEADROOM`（ERR 10），**不静默出数**；已到最大档（1 MΩ）且 `ρ<0.12` → `MEAS_ERR_RANGE`。
- 自动量程**先按粗测结果直接跳到目标档**，避免逐档步进（逐档 6 次 ×15 ms = 90 ms，纯浪费）；只有粗测异常时才逐档扫描兜底。

### 6.5 类型识别（R / C / L）

主判据用 **D = Rs/|Xs|**（相位），辅判据用 **双频 |Z| 斜率**：

| 判据 | 条件 | 结论 |
|---|---|---|
| 主 | `\|φ\| < 5.7°`（D < 0.1） | **R** |
| 主 | `φ < −84°`（D < 0.1，容性） | **C** |
| 主 | `φ > +84°`（D < 0.1，感性） | **L** |
| 辅 | `\|Z\|(10 kHz)/\|Z\|(1 kHz) < 0.2` | C（`≈0.1` 为理想电容） |
| 辅 | `\|Z\|(10 kHz)/\|Z\|(1 kHz) > 5` | L（`≈10` 为理想电感） |
| 辅 | 比值在 `0.5–2` | R |
| 冲突 | 主判据与辅判据不一致 | 取斜率结论，`confidence` 降为 1，显示“类型不确定” |

- **为什么是 5.7° 而不是 `硬件接口.md` 的 10°**：判据 `|φ|<θ` 等价于 `|X|/R < tanθ`——5.7° 对应 `|X|<0.1R`（“以 R 为基准的相对电抗 <10%”），10° 会放宽到 17.6%，把 5.7°–10° 的阻性-感性边界件（低 Q 电感、高频电阻）也判成 R。相角语义：电容 `φ = −90° + atan(D)`（D=0.1–0.3 → −84°–−73°），电感 `φ = +90° − atan(D)`，都不可能落入 R 窗，**电解电容不会被误判**（此处已按 `prin_a.md`/`math_spec.md` 更正早期表述）。真正的 R 窗风险只有：低 Q 电感（Q<0.1）、超低阻抗高 D 电容（D>10，φ≈−4.5°）、电阻自身高频感性（1 kHz 下可忽略）。
- 类型确认后仍显示 `Rs + D` 或 `Cs + D` 或 `Ls + Q`（串联模型）；`Cp/Rp/Lp` 由串联值换算出，仅作参考显示。电解电容必须按 **Cs** 显示，否则与商用表差 1–9%。
- `confidence`：类型判据清晰 + `cal_level=3` + `spread<0.1%` → 3；缺一项降 1。

### 6.6 参数提取与结果结构（`results.c`）

```
Zx = Rs + jXs
\|Z\| = √(Rs²+Xs²),  φ = atan2(Xs, Rs)
D  = Rs/|Xs|          （损耗角正切；仅对有抗部分有意义）
Q  = |Xs|/Rs
Cs = −1/(2πf·Xs)      （Xs<0）
Ls = Xs/(2πf)         （Xs>0）
Cp = Cs/(1+D²)       Lp = Ls(1+1/Q²)      Rp = Rs(1+Q²)
```

- 显示有效位：主参数 4 位有效数字 + 工程前缀（p/n/µ/m/k/M）；`D/Q` 3 位小数；`φ` 1 位小数（度）；`|Z|` 4 位有效数字。
- 输出同时携带 `f_hz`（DDS 实际频率）、`range`、`cal_level`、`confidence`、`spread`、`h2`、`clip`、`time_ms`、`retries`。
- 单位换算与格式化全部在 `results.c`，**用定点整数格式化**（去掉 `-u_printf_float`，省 10 KB Flash，见 §8.4）；浮点只参与数值计算。

| 发挥项 | 测量策略 |
|---|---|
| 100 kHz C 100 pF–100 nF | 100 kHz 下按 `ρ=Rf/\|Z\|≈0.6` 选档：**100 pF→10 kΩ 档**（`\|Z\|`=15.9 kΩ，`ρ=0.63`）、**1 nF→1 kΩ**（1.59 kΩ，0.63）、**10 nF→100 Ω**（159 Ω，0.63）、**100 nF→10 Ω**（15.9 Ω，0.63）。100 pF 的最优点其实是 4.8 kΩ，硬件没有，10 kΩ 是最近合法档 |

> **100 kHz 选档定稿（P0 问题已解）**：`100 pF@100 kHz` 的 `|Z|=15.9 kΩ`，要让 `ρ≈0.3` 需 `Rf≈4.8 kΩ`，硬件没有；**10 kΩ 档 `ρ=0.63` 正好落在 MARGIN_GOOD**（`|Vo|=0.315 Vrms`），即合法选择。`100 kΩ` 档留给 `10 pF`（`|Z|=159 kΩ`，`ρ=0.63`）。
> 同理修正 `1 nF`：`|Z|=1.59 kΩ`，应配 **1 kΩ 档**（`ρ=0.63`），不是 100 kΩ 档（那是 10 kHz 下的结论）。电容 100 pF→100 nF 实际走 **10 k→1 k→100→10 Ω** 四档，`ρ` 都约 0.6；电感 10 µH→1 mH 走 **10 Ω→100 Ω→1 kΩ** 三档，`ρ` 都约 1.59——**唯一 ρ>1 的测点，属风险项**：10 µH 仅典型件可行，须 AWD + M1 实测裁决（§6.4、§12 R14）。

## 7. 校准体系（`cal.c`）

> 校准是本题**精度指标的唯一出路**：R 1%、C/L 2%、100 kHz 发挥项、10 pF 级 5%、R 0.5% 全部依赖“α + 开路 + 双负载 + 通道失配”的联合修正。**校准不是可选功能，而是测量流程的一部分。**

### 7.1 校准项总览

| 校准项 | 物理模型 | 标定维度 | 数据量 | 不校准的后果 |
|---|---|---|---|---|
| **α 通道失配** | 两路调理+ADC 的复增益比 `g1/g2` | 4 频点 | 4 个复数 | 0.5% 幅值、0.5° 相位 → R 1% 指标直接失守 |
| **开路 Z_open** | 夹具/布线并联杂散 `Zp`（1–3 pF）+ 串联 `Zs` | 4 频点 × 6 档（仅合法组合） | ≤24 个复数 | 10 pF 时 10–30% 误差 |
| **双负载**（替代短路） | 串联残差 `Zs`、增益 `k` | 4 频点 × 6 档 | ≤48 个复数 | 10 Ω 档 1%、Rf 公差 0.1–1% → R 0.5% 指标失守 |
| **电平系数** | `k_in/k_out`：码值→rms | 1 kHz，1 次 | 2 个实数 | 只影响 \|Vin\|/\|Vo\| 显示与诊断，不影响比值 |

**校准等级 `cal_level`**（随每条结果返回）：

| 等级 | 条件 | 结果可信度 |
|---|---|---|
| 0 | 无数据（出厂名义 Rf） | 仅能定性；误差 1–5% |
| 1 | 仅 α | R 1% 边缘；C/L 2–5% |
| 2 | α + 开路 | R 1%、C/L 1–2%；10 pF 仍差 |
| 3 | α + 开路 + 双负载（**目标状态**） | 基础指标全过；发挥项达标 |
| 4 | 3 + 台架复检通过（夹具未动） | 可用于 100 kHz / 10 pF 级 |

### 7.2 α 通道失配标定（K78/CAL 开关）

**硬件**（`afe.md` Q3，2026-11-15 终版）：K7（K78，PD6）为 G6K-2F-Y 双刀双掷；**不吸合 = 正常测量**（失效安全：线圈断线只失去校准能力，不破坏测量）。吸合时 A 刀把 CH1 输入从 S+ 切到 CAL、B 刀把 CH2 输入从 VO 切到 CAL。**CAL 源 = U17B（OPA2810）跟随 TP1/F+ 输出，经 100 Ω 串联电阻**送到 K7 的两个 NO 触点；K7 之后每通道各有一只 **1 kΩ + 100 pF + BAT54S 钳位**的 RC 网络——这部分是两路通道差异的来源，**计入 α**。

**α 的物理定义与计算式**：

```
α(f) ≡ m1(f)/m2(f) = g1(f)/g2(f)
测量母公式：Zx = −Zf_eff(f)·(m1/m2)/α
```

其中 m1、m2 为 K7 之后 CH1（Vin 支路）与 CH2（Vo 支路）的复增益。α 只校正“K7 之后到 ADC”的通道差异。

**α 计入 / 不计入的项**（避免重复或漏校）：

- **计入 α（每通道独立、成对差异）**：R21/R40（1 kΩ 0.1%）、C33/C47（100 pF）、BAT54S ×2（钳位结电容）、1 µF 耦合、100 kΩ 分压到 VBIAS、OPA2320 两级跟随（增益/相位/GBW）、100 Ω + 1 nF 抗混叠 RC、ADC 采样保持输入电容与两路输入网络差异。
- **不计入 α（由双负载 `k` 或母公式吸收）**：S+/VO 源阻抗（由 `k` 与 `Zs` 吸收）、BUF634A 与 I-V 转换器的有限增益差（由 `k` 吸收）、CAL 源本身的 100 Ω（两路共模，不出现在 α 中）。
- **α 不可省略、也不可单独使用**：它是 `k` 的输入之一；α 的残余误差由 §7.5 的复测验收直接卡住。

**流程（`cal_measure_alpha`）**：

1. 继电器全部归位（10 kΩ 默认档）、DDS 静音解除、等 ≥20 ms；
2. `PD6=1` → 等 ≥5 ms（继电器动作 ≤3 ms + 稳定余量）；
3. 依次四频点：`dds_set_freq(f)` → `adc_acquire(N=1024, K=2)` → `dsp_analyze` → `α(f) = m1/m2`（复数，双块复比值平均）；
4. `PD6=0` → 等 5 ms → 恢复测量态；
5. 合法检查：`|α−1| < 2%`、`|arg α| < 1°`（两路设计对称，偏差过大说明硬件异常）；
6. 存 Flash（`cal.alpha[4]`，成对 double 复数），`cal_level` 至少升到 1。

**边界**：α 只覆盖 **K7 之后**的通道差异；K7 之前的 CAL 源/走线是共模，不进入 α。α 未标定时测量仍可进行，但 `confidence` 降级、`diag` 置 `CAL_LEVEL<3`。
### 7.3 开路标定

**做法**：夹具空置（不接 DUT、也不短接），逐（频率, 档位）合法组合采集 `Zm_open`。此时期望 `Zm = Zs + k·Zp`，其中 `Zp` 主要是夹具并联杂散电容 C_stray（1–3 pF）。

- 存**原始复数** `z_open[range][freq]`（不在采集时就分解），使其可随模型升级重算；同时存 `method`（见下）。
- **有效性判据（两条件并列，任一不满足即该组合 `valid=0`）**：
  1. `|Zm_open|/Rf ∈ [1, 100]`（信噪比窗口；>100 低频大档噪声主导，<1 异常）；
  2. `|Vo_open| ≥ 1 mVrms`（ADC 端确实可测，避免“数值上过窗口、实际全是噪声”的假有效）。
  不满足时反解按 `Zp=0` 处理（此时开短路修正贡献 <1%，可忽略），并置 `method=1`（退化模式）。
- **method 退化分支**（记录里保存 `method`，测量时按它选择反解路径）：
  - `method=0`（正常）：`Zp` 由开路 + 双负载实测解出，反解 `Zx=Zp·X/(Zp−X)`；
  - `method=1`（退化）：开路不可测/无效时，用**名义 Cf 两点解**——反馈阻抗解析式 `Zf_eff(f)=Rf/(1+j2πfRfCf)` 的 `Cf` 取名义值（各档按 PCB 参数/实测），只用 `Zs/k` 反解 `X` 并把 `Zp` 置 0。**精度预算**（Cf 名义值误差 10% 时）：10 kΩ 档 100 kHz 附加误差约 **0.19%**（可接受）；100 kΩ 档约 **1.9%**（**必须实测，不允许 method=1**）；1 MΩ 档 ≤1 kHz 约 **0.02%**（可用，推荐实测）。
- **夹具不变性检查**（发挥项 10 pF 的生命线）：把 `Zm_open` 换算成等效杂散电容 `C_stray`，与存储值比较；**变化 >0.2 pF 即置 `cal_stale`**，串口/OLED 提示“夹具已移动，请重新开路校准”。10 pF 时 0.2 pF 已是 2%，必须卡住。
- 该检查在每次开机自检时自动做一次（10 kHz/10 kΩ 组合，耗时 ~16 ms）。
### 7.4 串联残差与增益：双负载两点法（**不做短路校准**）

#### 7.4.1 为什么本硬件不能做短路校准

| 事实 | 后果 |
|---|---|
| 激励固定 0.5 Vrms（无程控幅度） | 无法按 `硬件接口.md` 建议“降到 ~5 mVrms” |
| 短路阻抗 ≈0.1 Ω → 电流 ≈5 A | 远超任何器件能力 |
| **F+ 路径无任何限流元件** | 真短路时 5 A 只被 BUF634A 的短路限流钳住（**±375 mA min / ±550 mA typ**） |
| 10 Ω 档 Rf 峰值耗散 = (0.55 A)² × 10 ≈ **3 W** | Rf（0.1% 金属膜 1/4 W 级）立即烧毁 |

因此 **`CAL S`（短路校准）在本硬件上不提供**；串口收到 `CAL S` 返回 `ERR 9 CAL_S_UNSUPPORTED` 并说明原因（见 §8.5、§14 D7）。

#### 7.4.2 双负载两点法

用**两只 0.1% 金属膜电阻**（同一档位、比例约 10×）代替短路，得到足够方程数同时解出 `Zs`、`k`（并复用开路结果解 `Zp`）。

标准负载表（建议值，允许按实物调整；**1 MΩ 档标准负载 = Z1=1 MΩ、Z2=10 MΩ，ρ=1/0.1**）：

| 档位 Rf | 负载 Z1 | 负载 Z2 | 说明 |
|---|---|---|---|
| 10 Ω | 10 Ω 0.1% | 100 Ω 0.1% | Z1 时 `ρ≈1`，正是 10 Ω 档额定工作点 |
| 100 Ω | 100 Ω | 1 kΩ | |
| 1 kΩ | 1 kΩ | 10 kΩ | 1 kΩ 是基础指标的“中坚档” |
| 10 kΩ | 10 kΩ | 100 kΩ | 默认档，必须最准 |
| 100 kΩ | 100 kΩ | 1 MΩ | |
| 1 MΩ | **1 MΩ 0.1%** | **10 MΩ 0.1%** | ρ=1/0.1；1 MΩ 档只允许 ≤1 kHz（10 kHz 仅校准后） |

> 采购提示：10 MΩ 0.1% 电阻不易买，可用 **10 只 1 MΩ 0.1% 串联**（注意支架绝缘与表面漏电，测试前用无水乙醇清洗并干燥）；若条件不足，Z2 取 2 MΩ（ρ=0.5）也可解，但条件数变差、两点差比从 10× 降到 2×，须加倍关注 `|W_1−W_2|` 判据（§7.4.2 条件数第 1 条）。

**入解硬规则**（每个负载点独立判定，任一不满足则该点不参与求解）：

1. `ρ_i = Rf/|Zstd_i| ∈ [0.1, 1]`（与量程窗口一致：ρ 过大→|Vo| 太小、ρ 过小→削顶）；
2. 该点采集 `clip == 0`（未削顶）；
3. 该点块间 `spread < 0.5%`（离散度过大说明接触不良/噪声，重测）。

**模型与闭式解**（全部复数运算；`Zx∥Zp` 表示并联）：

```
观测模型：  Zm = Zs + k·(Zx ∥ Zp)
开路：      Z_open = Zs + k·Zp
负载 i：    A_i ≡ (Zm_i − Z_open)/k = −Zp²/(Zstd_i + Zp)      (i=1,2)

① 由 A_1/A_2 消去 k：
   Zp = (A_2·Zstd_2 − A_1·Zstd_1)/(A_1 − A_2)
   其中 A_i 只需比例，实现上直接用 W_i ≡ Zm_i − Z_open（与 A_i 差常数因子 k）：
   Zp = (W_2·Zstd_2 − W_1·Zstd_1)/(W_1 − W_2)

② 回代求 k：
   k = W_1 / (−Zp²/(Zstd_1 + Zp))

③ 求串联残差（两点回代取平均，降低接触误差）：
   Zs = mean( Zm_1 − k·(Zstd_1∥Zp),  Zm_2 − k·(Zstd_2∥Zp) )
```

**条件数与反解判据**（全部复数；`W_i = Zm_i − Z_open`）：

1. `|W_1 − W_2| > 1e-3·max(|W_1|,|W_2|)`（两点不能重合，否则 Zp 公式分母病态）；
2. open 与每个负载点各重复 3 次，重复性 `|ΔZ|/|Z| < 1e-3`（否则判定夹具/接触不稳定，重测）；
3. 反解要求 `|Zp − X| > 0.1·|Zp|`（等价 `|Zx| < 10·|Zp|`）；不满足则放大倍数 >100×，**拒绝并把 Zp 视为失效**（按 method=1 处理、`diag` 置 `LOAD_INVALID`）；
4. `|Zp| > 100·max(|Z_1|,|Z_2|)` → `Zp=∞`（夹具杂散可忽略，按 method=1）；
5. 灵敏度示例（说明为什么必须有第 3/4 条）：10 pF@100 kHz 时 1 pF 的 Zp 误差被放大 **1.21×**；1 MΩ@1 kHz 时 Zp 残差被放大 **6.6×**。

**反解（测量时）**：

```
X  = (Zm − Zs)/k
Zx = Zp·X/(Zp − X)                 （Zp 有效时）
Zx = X                             （Zp 无效/未标定时，Zs、k 仍有效）
```

**验证**：另用第三只 0.1% 电阻（如 4.99 kΩ / 49.9 kΩ 档）做检查件，误差应 **<0.1%**；若超限，说明负载接触不良或 `Z_open` 过期，拒绝把 `cal_level` 置 3。

**为什么这个模型够用**：

- `k` 吸收了 Rf 实际公差、I-V 有限增益、α 残余、继电器 `R_on` 的**一阶项**；
- `Zs` 吸收了触点/走线串联残差（对 10 Ω 档至关重要）；
- `Zp` 吸收了夹具并联杂散（对 10 pF / 100 pF 至关重要）；
- 残留的一阶误差（如 Rf∥Cf 的频响）由 `Zf_eff(f) = Rf/(1+j2πfRfCf)` 的解析修正 + 双负载在**每频率**标定共同吸收。
### 7.5 校准流程、顺序与夹具不变性

**强制顺序**：`α（每频）→ 开路（每频×每档）→ 双负载（每频×每档）→ 存 Flash → 检查件验证`。换夹具/换电缆/换 PCB/松开夹具螺丝后，**开路与双负载必须全部重做**（10 pF 档尤其）。

| 项 | 目标 | 验收方法 |
|---|---|---|
| α 残余 | <0.05%、<0.02° | 校准后在同一 CAL 网络复测，比较两路幅度/相位 |
| 开路残差 | 10 pF 档贡献 <1%（等价 C_stray 复现 <0.1 pF） | 校准后重测开路，反算 C_stray |
| 双负载残差 | 检查件误差 <0.1%（10 kΩ 档） | 4.99 kΩ/49.9 kΩ 0.1% 检查件 |
| 短路残差 | 不适用（无短路校准） | — |
| 温度 | 记录 `temp_c`，>5 °C 变化提示复校 | 片内温度传感器（可选） |

**时间估算（一致模型：标定一律 N=256 块，不做 1024 点精测）**：块时长 = 256/fs，100 Hz 组合 **160 ms/块**、1 kHz 16 ms、10 kHz 1.6 ms、100 kHz（S=12，fs=1.2 MSPS）0.213 ms（含换档/开销按 ≤2.13 ms 上限计）。

| 步骤 | 组合数 | 估计 |
|---|---|---|
| α | 4 频 × 2 块 | ≈ 0.36 s（100 Hz 占 0.32 s） |
| 开路 | **按“所需频率 × 档位”合法子集**（非全 4×6）：1 MΩ 档 ≤1 kHz、100 kHz 只做 10 Ω–100 kΩ | ≈ 3–6 s |
| 双负载 | 每档 × 合法频率 × 2 只负载 × 2 块 | ≈ 8–12 s |
| 存 Flash + 检查件 | 1 次写 + 1 次复测 | ≈ 0.1 s |
| **合计** | | **≈ 12–18 s**（不含人工换标准件） |

- 支持 `CAL O`（开路）与 `CAL L`（双负载）**分段续做**：每一步完成即写一条记录（`method`/`cal_level` 随记录走），中途断电不丢失已完成段；重新上电可从 `CAL O`/`CAL L` 继续。
- 全量校准是台架一次性工作，不进测量实时路径（§9 的时间预算不含校准）。
### 7.6 Flash 存储与记录式布局（sector6 + sector7 双扇区 A/B）

**原则**：代码区上限 **256 KB**（0x08000000–0x0803FFFF），校准区 = **sector6（0x08040000–0x0805FFFF）+ sector7（0x08060000–0x0807FFFF）两个 128 KB 扇区**，交替作为 A/B 记录区。F4 只能整扇区擦除：擦一个扇区时另一个仍保有**完整上一版记录**——这是“擦除窗口掉电安全”的唯一实现方式；编程窗口掉电则靠 CRC+seq 取最新有效记录。

| 项 | 设计 |
|---|---|
| 分区 | 代码区 0x08000000–0x0803FFFF（**256 KB**）；校准区 sector6 0x08040000–0x0805FFFF + sector7 0x08060000–0x0807FFFF（各 128 KB）；见 §8.2 |
| 记录结构 | `cal_blob_t` **v2**：`magic(4) version(2) method(2) flags(2) timestamp(4) seq(4) crc32(4)` = **24 B**（含 2 B pad）；`alpha[4]` 复数 double = **64 B**；`k[4][6]`、`zs[4][6]`、`zp[4][6]` 各 24 组复数 double = **各 384 B**；合计 **1240 B** |
| 求解精度 | 校准求解全程 **double**（不复用 float；标定是一次性台架工作，时间不是问题） |
| 槽位 | **1536 B/槽**（含对齐/CRC 余量），每扇区 128 KB / 1536 B = **85 槽**；A/B 双扇区交替使用 |
| 写时序 | 1240 B ≈ 310 word × 16 µs ≈ **4.96 ms**；擦写函数放 `.ramfunc`（擦写期间不能从 Flash 取指），关中断，写前后喂狗 |
| 擦除 | typ **1 s** / max **4 s**（整扇区）；仅在“当前扇区 85 槽写满”或启动发现对侧扇区无效时触发；擦除期间关中断并喂狗 |
| 寄存器 | FLASH_KEYR=0x45670123/0xCDEF89AB；CR.PSIZE=x32（3.3 V）、SER+SNB=**6 或 7**；失败重试一次后放弃并报 `FLASH_ERR` |
| 掉电语义（必须按此实现与验收） | ① **编程窗口掉电安全**：槽写入中掉电，该槽 CRC 失败被跳过，启动取 seq 最大且 CRC 通过的有效记录；② **擦除窗口掉电**：正在擦的扇区内容不确定，但**另一扇区完整**，启动自动回退该扇区的记录；③ 两个扇区都无有效记录 → 名义表 + `cal_level=0` + `cal_stale`，串口/OLED 提示“未校准，请执行 CAL A/O/L” |
| 启动选择流程 | 扫 sector6 与 sector7 的**所有槽**（校验 magic/version/长度/CRC32）→ 收集有效记录 → `seq` 最大者为当前记录 → 装入 RAM 副本 → 若该扇区“可追加”（已用槽 <85）则续写，否则下次保存切到另一扇区（先擦后写） |
| 缺省回退 | 无有效记录 → 名义表 `Rf = {10,100,1e3,1e4,1e5,1e6}`、`Zs=0.1 Ω`、`Zp=0`、`α=1`、`method=1`，`cal_level=0` |
### 7.7 校准与测量内核的接口（错误与降级）

- `cal_apply_impedance(&cal, freq, range, &zm, &zx, &diag)` 内部完成 §7.4 反解；`diag` 返回 `CAL_LEVEL`、`OPEN_VALID`、`LOAD_VALID`、`STALE` 位。
- 若目标（频率,档位）在 `range_freq_legal` 中非法或 `cal_level<2`：结果仍返回，但 `confidence` 降级、串口带 `warn=CAL`，OLED 显示“未校准”。
- 若实测 `|Zm|` 与 `ρ` 落在窗口内但校准残差异常（例如 `|Zs| > 1 Ω`、`|Zp|` 符号不对）：不沿用旧值，强制走一次快速开路复测（1 kHz/10 kHz 两点）后再测。

## 8. 内存、Flash、构建与应用层集成

### 8.1 内存布局与链接脚本

STM32F407VET6：**SRAM 128 KB @0x20000000**、**CCM 64 KB @0x10000000（仅 CPU 可访问）**、Flash 512 KB @0x08000000。分配原则：**DMA 只碰 SRAM；CCM 给 CPU 热数据；栈在 SRAM 顶部且与堆隔离。**

| 段 | 位置 | 大小（预算） | 内容 |
|---|---|---|---|
| `.isr_vector / .text / .rodata` | Flash 0x08000000– | ≤256 KB | 代码、常量表、字库、金标准向量 |
| `.data` | RAM | ~1 KB | 已初始化变量 |
| `.bss` | RAM | ~9 KB | 零初始化变量（含 cal 记录 RAM 副本 1240 B，明细见 §8.3） |
| `.dma_buf`（自定义，32 对齐） | RAM | **8 KB** | `adc_dma_buf[2×1024]`（uint32，CDR 打包） |
| `.ccmram`（NOLOAD，KEEP） | CCM | ≤8 KB | DFT 相位表、热循环缓存（CPU 用，DMA 永不引用） |
| 栈 | RAM 顶部（`_estack=0x20020000` 向下） | **4 KB** | 主栈；ISR 共用；`[__StackLimit,_estack)` 启动填 0xDEADBEEF 检测溢出 |
| 堆 | — | **0** | 禁用 `malloc`；`_sbrk` 软上限保护 |

关键链接约束（`firmware/STM32F407VETx_FLASH.ld`）：

```ld
MEMORY
{
  FLASH  (rx)  : ORIGIN = 0x08000000, LENGTH = 256K    /* sector6+sector7 留给校准 */
  RAM    (xrw) : ORIGIN = 0x20000000, LENGTH = 128K
  CCMRAM (rw)  : ORIGIN = 0x10000000, LENGTH = 64K
}
_estack         = ORIGIN(RAM) + LENGTH(RAM);           /* 0x20020000 */
_Min_Stack_Size = 0x1000;                              /* 4 KB */
_Min_Heap_Size  = 0;                                   /* 不使用堆 */
__StackLimit    = _estack - _Min_Stack_Size;           /* 0x2001F000 */
ASSERT(_ebss + _Min_Heap_Size + _Min_Stack_Size <= _estack, "RAM overflow")
ASSERT(LOADADDR(.data) + SIZEOF(.data) <= 0x08040000, "code+data overflows 256K")
```

- `.dma_buf`：`NOLOAD`、32 B 对齐、`KEEP(*(.dma_buf))`（`--gc-sections` 会回收未被代码引用的段）；用 `ASSERT` 保证 `_dma_buf_start >= ORIGIN(RAM)` 且 `_dma_buf_end <= __StackLimit`。**F4 DMA 无 64 KB 边界约束，不要加这条。**
- `.ccmram`：`NOLOAD` + `KEEP(*(.ccmram))`。**NOLOAD 段不会从 Flash 初始化**：若放常量/相位表，必须在 `board_init()`/`dsp_init()` 里**运行期计算**，或另加“Flash→CCM 拷贝”规则；否则值不确定。
- 启动时（startup 在 `bl main` 之前，或 `board_init()` 最前）把 `[__StackLimit, _estack)` 填 0xDEADBEEF（4 KB，约 10 µs）；`selftest` 从 `__StackLimit` 向上扫第一个非填充字得到栈高水位，余量 <1 KB（高水位 >3 KB）时置 `0x00004000 STACK_NEAR`。
- 栈**不放 CCM**：CCM 只挂 CPU 总线，与 SRAM 抢总线会放大中断延迟；现有 startup 默认栈在 SRAM，保持不变。
- `_sbrk` 替换 libnosys 版本：`heap_end + incr > __StackLimit` 时返回 `(void*)-1` 并置 `errno=ENOMEM`，防止 `printf`/浮点异常静默压栈。

**实测验证**（本机 arm-none-eabi-gcc 14.2.1；用现有 Day1 对象 + 上述 ld 改造实链，**exit 0**）：


### 8.2 Flash 分区（与 `硬件接口.md` 的差异）

| 区域 | 地址 | 大小 | 用途 |
|---|---|---|---|
| 代码区 | 0x08000000–0x0803FFFF | **256 KB** | 固件（预计 60–90 KB，余量 ≥2.8×） |
| 校准区 A | 0x08040000–0x0805FFFF（sector 6） | **128 KB** | 85 × 1536 B 记录槽（A/B 双扇区之一） |
| 校准区 B | 0x08060000–0x0807FFFF（sector 7） | **128 KB** | 85 × 1536 B 记录槽（A/B 双扇区之一） |

`硬件接口.md` 写“校准存 0x0807F000 之后 1 页（4 KB）”：0x0807F000 是 sector7 的最后一页，按 1536 B/条只能放 **2 条**记录（旧版 512 B 记录也只有 8 条），既不够双扇区 A/B，也无法覆盖“代码增长到 256 KB 以上”的余量。终版改为 **sector6+sector7 共 256 KB 校准区、代码 256 KB**，此差异列入 §14（D17）。

**构建期校验**（`tools/check_map.py`，POST_BUILD 运行；纯 stdlib，不需要 numpy）：

- 符号断言（比解析 map 文本更稳：map 里是 `load address 0x...` 列与 `_sidata` 符号，没有字面 `LOADADDR(...)`）：
  - `_sidata + (_edata - _sdata) <= 0x08040000`（代码+已初始化数据不越过 256 KB 代码区）；
  - `_ebss <= __StackLimit`（.bss 不压栈保护区；等价于 §8.1 ld 的 `_ebss + _Min_Stack_Size <= _estack`）；
  - `.dma_buf` 段地址 ∈ [0x20000000, 0x20020000)、`.ccmram` 段地址 ∈ [0x10000000, 0x10010000)；
  - `__StackLimit == _estack - 0x1000`；
- 任一失败 → 构建失败（exit 1），不允许“先烧了再说”；
- ld 内的 `ASSERT` 同时保留（链接期就失败，比 POST_BUILD 更早）。

**测试**：故意把 FLASH 改回 512K、或把 `.dma_buf` 放到 CCM，确认 check_map 与链接 ASSERT 分别能拦下（M0 验收项之一）。
### 8.3 静态内存清单（预算）

| 项 | 大小 | 所在段 | 说明 |
|---|---|---|---|
| ADC DMA 双缓冲 | 8 KB | `.dma_buf`（SRAM） | 2×1024×uint32；DMA 不可访问 CCM |
| OLED 帧缓冲 | 1 KB | `.bss` | 128×64 位图 |
| UART RX 环 | 256 B | `.bss` | 已有骨架；加溢出计数 |
| UART TX 环 | 512 B | `.bss` | 非阻塞发送（§4.5） |
| 日志环 | 1 KB | `.bss` | 最近 16 条事件（掉电不保） |

| DFT 工作区/累加器 | ≤4 KB | `.bss` | 16/12 相累加器、复数中间量 |
| DFT 相位表/热循环 | ≤8 KB | `.ccmram` | NOLOAD，运行期算（§8.1） |

| **RAM 合计** | **≈21–22 KB / 128 KB（17%）** | | 余 ~106 KB 可扩展 |

**§8.1 段 ↔ §8.3 明细映射**（消除旧版“7.24 KB vs 6 KB”不自洽）：

| §8.1 段 | §8.3 明细项 | 预算 |
|---|---|---|
| `.data` | 全局已初始化变量 | ~1 KB |
| `.bss` | OLED 1 KB + UART RX 256 B + TX 512 B + 日志 1 KB + cal 副本 1240 B + DFT 工作区 4 KB + 其他（DDS/状态机/printf 缓冲）≈1.2 KB | **≈9.2 KB** |

### 8.4 构建体系与编译选项

**工具链**（实测）：`arm-none-eabi-gcc 14.2.1 20241119`、newlib 4.4.0、cmake 4.4.4、ninja 1.13.2；DAPmini CMSIS-DAP + pyocd 0.46.1（`-t stm32f407vetx`）。当前仓库骨架可用：`tools/build.ps1` Debug/Release 均 0 warning，Flash 实占 17.6 KB。

**CMake 目标结构**（建议）：单一 target `lcr-fw`（不编译 HAL 源，只用 `stm32f407xx.h` 的位定义；CMSIS `system_stm32f4xx.c` + startup 保留），外加**不存在**的 host target（本机没有 host 编译器，见 §8.6）。

```
-std=gnu11 -mcpu=cortex-m4 -mthumb -mfpu=fpv4-sp-d16 -mfloat-abi=hard
-ffunction-sections -fdata-sections -fno-common
-Wall -Wextra -Wno-unused-parameter -Wdouble-promotion -Wshadow -Wformat=2 -Wundef
-Og -g3（Debug） / -O2 -g（Release）
链接：-T STM32F407VETx_FLASH.ld -Wl,--gc-sections -Wl,--print-memory-usage
      -Wl,--no-warn-rwx-segments -specs=nano.specs -specs=nosys.specs -lm
```

必须做的修正（否则构建/烧录会踩坑）：

1. **去掉 `-u_printf_float`**：实测加回后 text 从 4.7 KB→14.9 KB（+10.1 KB），且 `%f` 走 `_dtoa_r → _calloc_r → malloc`；本设计**全部结果用定点整数格式化**（`results.c`），浮点只参与计算不在 printf 里出现。
2. **补 `syscalls.c`**：实现 `_write/_read/_close/_lseek/_fstat/_isatty/_kill/_getpid` 空桩，消除 8 条链接警告并让 `write(1,…)` 直通 UART（可省掉 `printf` 重定向的缓冲层）。
3. **ELF 后缀**：`set_target_properties(lcr-fw PROPERTIES SUFFIX ".elf")`，否则 `build.ps1` 找不到 ELF（**已修**：现产物 `firmware/build/lcr-fw.elf` 747,176 B，`firmware/CMakeLists.txt` 已加该行）。
4. **`CMAKE_TRY_COMPILE_TARGET_TYPE=STATIC_LIBRARY`** 必须在 `project()` 之前；否则交叉编译探测失败。
5. **中文路径**：POST_BUILD 的 objcopy 用相对文件名 + `WORKING_DIRECTORY`；路径含中文时不要经 cmd 拼接。
6. 所有 `.ps1` 用 **UTF-8 with BOM**；`build.ps1` 需加 `-Test`/`-Verbose` 并透传 `$LASTEXITCODE`（当前 5 处小 bug，见 fw_base.md）。
7. **Python 解释器必须显式指定**：实测 `find_package(Python3)` 会命中 `C:/Users/Finaqusity/.local/bin/python3.12.exe`（3.12.12，**无 numpy、无 pyserial**）；本机依赖环境是 `C:\Users\Finaqusity\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe`（3.12.14，numpy 2.3.5、pyserial 3.5）。`build.ps1` 用 `Find-Exe` 找到依赖 Python 后显式传 `-DPython3_EXECUTABLE=<该路径>`；POST_BUILD 一律用 `${Python3_EXECUTABLE}`，不要用 PATH 上的 `python`（本机 PATH 上是 Microsoft Store 别名，不可用）。
8. **`check_map.py` 只用标准库**（不依赖 numpy）：构建期校验必须能在任何 Python 3 下运行；`gen_golden.py`（numpy）只在需要刷新金标准向量时手动运行，且必须用第 7 条的依赖 Python。

**构建流水线**：`build.ps1` → configure（缓存 toolchain）→ build → 产物 `firmware/build/lcr-fw.{elf,hex,bin,map}` → `check_map.py` 校验 → 可选 `gen_golden.py` 刷新测试向量；`flash.ps1` 增加 `-Verify`（pyocd verify）与 `--erase chip` 选项。

**IDE**：仓库已提交共享 `.vscode/`（cmake.sourceDirectory=`firmware`、compile_commands IntelliSense、`Ctrl+Shift+B` 编译任务、Cortex-Debug+pyOCD `F5` 调试）。CubeMX 只作配置仪表盘（时钟树/引脚对照），生成代码放 gitignore 的 `firmware/_cubemx/` 作参考，不参与产品构建——详见 `docs/开发环境.md` §5–§6。

### 8.5 启动流程、主循环与应用层

**启动**（详见 §4.7 顺序，总计 <350 ms）：

```
复位 → 向量表/FPU → SystemInit(168 MHz) → board_init（GPIO 安全态：PD0–PD6 尽早输出低）
→ uart_init → 20 ms 等待 → dds_init → relay_init → adc_init（配好不启动）
→ i2c_oled_init（失败降级）→ cal_init（读 Flash、CRC、cal_level）→ selftest（含开路残差检查）
→ main loop
```

**主循环（事件驱动，无 RTOS）**：

```
while (1) {
    proto_poll();              /* 非阻塞：解析 UART 行命令 */
    if (evt_take(&e)) ui_event(&e);   /* 测量完成/按键/错误 → OLED 刷新 */
    ui_poll();                 /* 慢路径：只在空闲时刷 OLED 整页 */
    if (auto_measure_due()) meas_auto(&res);   /* 上电自动测量 / 周期重测 */
    wdg_feed();
}
```

**“一键启动”的实现**（引脚表无按键，这是本题的一个硬缺口）：

1. **上电自动测量一次**（默认行为）：校准就绪后自动调用 `meas_auto()`，OLED 直接显示结果——评委上电即见读数，符合题意“一键/无操作启动”；
2. **串口命令** `A`（自动测量）、`M`（按当前设置测一次）；
3. **可选软件按键**：PD7 配置为**内部上拉输入**（硬件已有下拉电阻，需实物确认电平逻辑；若冲突则放弃），10 ms 消抖，检测到有效边沿触发一次 `meas_auto()`；`board_config.h` 用宏 `BOARD_HAS_USER_KEY` 开关，默认关闭以免与“PD7 备用输入”冲突；
4. 以上三者共用同一个 `meas_auto()` 入口，互斥（测量中拒绝新请求，返回 `BUSY`）。

**串口协议（ASCII 行，115200 8N1）**——兼容 `硬件接口.md` 建议并扩展：

| 命令 | 功能 | 返回 |
|---|---|---|
| `?` / `VER` | 帮助 / 版本 | 文本 |
| `F f` | 设频率（100/1000/10000/100000） | `OK F=f` |
| `R r` | 设量程 0–5（10Ω/100Ω/1k/10k/100k/1M） | `OK R=r` |
| `A` / `M` | 自动测量 / 按当前设置测一次 | 结果行（见下） |
| `CAL A` | α 标定 | `OK CAL_A level=…` |
| `CAL O` | 开路标定（当前档/全档） | `OK …` |
| `CAL L` | 双负载标定（当前档，需已接标准件） | `OK …` |
| `CAL S` | **明确报错**：“本硬件不支持短路校准” | `ERR 9 CAL_S_UNSUPPORTED` |
| `RAW ON` / `RAW n` / `RAW OFF` | 原始 ADC **快照**（采 1 块→停采→输出→自动 OFF；`RAW n` 指定块数 1–2） | `OK RAW N=…`，随后一帧；见下 |
| `SAVE` | 校准写 Flash | `OK SAVE seq=…` |
| `SCAN f1 f2 n` | 扫频扫描（发挥项/调试） | CSV 或结果行序列 |
| `LVL` / `T` / `I` | 电平诊断 / trace / 自检 | 文本 |

**结果行格式**（单行，便于 Excel 解析）：

```
Z,<|Z|>,<phi_deg>,R=<Rs>,X=<Xs>,type=<R|C|L>,val=<value>,unit=<ohm|F|H>,D=<D>,Q=<Q>,f=<f_dds>,range=<0-5>,cal=<level>,conf=<0-3>,spread=<%>,h2=<%>,t=<ms>,err=<code>
```

> 结果行实测约 **133 字符 → 11.55 ms @115200**（§9.2 的 P6 按 120 字符/10.42 ms 预算，偏乐观 1.1 ms；P6 预算按 160 B / 14 ms 取）。`err` 0–10 见 §13.4，协议层统一 `ERR <code> <NAME>`。

**RAW 二进制帧（快照模式，写死）**：`A5 5A | ver(1)=1 | flags(1) | len(2) | seq(4) | f0_mHz(4) | fs_hz(4) | S(1) | N(2) | data(N×u32) | crc16(2)`，小端；`len` = data 字节数（=4N）；`crc16` = CRC16-CCITT（poly=0x1021、init=0xFFFF、refin=refout=false），覆盖 `ver..data` 全部字节；`f0_mHz` 存实际 DDS 频率的 mHz（100 Hz 格点实际 99 986.792 mHz，不能用整数 Hz 截断）；`S`/`N` 供上位机核对（100 Hz/1 kHz/10 kHz：S=16、N=1024；100 kHz：S=12、N=1008）。采集 1 块 → 停 TIM2/DMA → 发送 → 自动 `RAW OFF`。115200 下 N=1024 帧 4114 B → **357 ms 不可能连续**；N=64 帧 274 B → 23.8 ms；连续观测请把波特率提到 **460800**（CH340 支持）或缩小 N。

**测量期间的协议规则**（防丢命令/防误解）：

- 测量进行中（`meas_auto` 阻塞）**RX 只收不发**：命令只进 256 B RX 环（115200 下约 22 ms 输入量），不解析、不响应；环满后新字节丢弃并累加 `rx_overflow`（`?` 帮助里可查）。
- 测量结束后按到达顺序逐条解析；单行超过 96 B 的命令整体丢弃（不截断执行）。
- 测量期间收到的 `A`/`M`：测量结束后回一行文本 `BUSY`（不带 err 码），不排队重测。
- 需要即时诊断请等测量结束（典型 105–877 ms）再发。

**OLED 页面**（128×64，SSD1306 类，4 线 I²C，模块自带 4.7–10 kΩ 上拉）：

| 页面 | 内容 |
|---|---|
| P0 主页面 | 大字：类型 + 数值 + 单位；第二行 `f=…  RANGE=…  CAL=…`；第三行 `D/Q/φ` |
| P1 诊断 | `Vin/Vo/ratio/α/ρ/clip/h2/spread/cal_level` |
| P2 校准状态 | 每档 open/load 有效性与时间戳、`cal_stale` 提示 |
| P3 自检 | boot_status 位掩码、DDS/ADC/继电器/OLED 结果 |

整屏刷新 23 ms、局部 2 页约 5.8 ms（400 kHz）；**只在空闲刷**，测量期间不改页，避免与采样抢时间。

### 8.6 主机侧测试（没有 host 编译器时的替代方案）

实测本机 **没有 gcc/clang/cl/mingw/make**，无法在 PC 上编译运行 C 单测。因此：

1. `tools/gen_golden.py`（Python 3.12 + numpy）生成**金标准向量**到 `firmware/test/vectors/*.h`：含任意相位的合成波形、已知 Zx 的反解期望值、α/开路/双负载闭式解的输入输出对、类型判别边界（φ=5.6°/5.8°、84°/86°）、12 组端到端用例；
2. 固件侧 `test.c`（`#ifdef LCR_SELFTEST`）把向量喂给 `dsp/cal/meas`，逐项比对（容差：幅度 1e-4、相位 1e-3°），结果经串口输出 `PASS/FAIL`；
3. `tools/run_onboard_tests.py` 自动烧录→运行→收集 PASS/FAIL；
4. `tools/lcr.py` 提供 `measure/scan/cal/raw/save/--json/--csv`，作为台架与验收脚本的基础。

这样“算法正确性”在没有任何仪器的条件下也能回归——这是架构里专门为“本机缺 host 编译器”设计的补偿路径。

## 9. 性能预算、时序与余量

### 9.1 CPU 预算（168 MHz，CPU 不是瓶颈）

| 项 | 成本 | 说明 |
|---|---|---|
| 相累加 | **每样本 4–8 cycles**（双通道） | 纯 int32 加法：`acc[p][ch] += sample`；无乘法、无浮点 |
| 一块 N=1024/1008 的 CPU | **33.0（S=12, N=1008）/ 36.6（S=16, N=1024）µs**（含分支与 DMA 检查；N=256 时 48.8 µs/1024 或按比例） | 占 100 kHz 采集窗 0.84 ms 的 ~4% |
| S 点 DFT（只算 bin1） | 128–512 cycles ≈ **1.5–3 µs** | 16 点或 12 点复数组合；相位表 ≤64 B |
| 朴素 1008 点 DFT 对照 | 32 256 cycles = **192 µs** | 本方案加速 ~5–7×，乘法少约 60× |
| `printf` 一行（6 个 float 的旧方案） | ≈3 000 cycles = 17.9 µs | 改定点格式化后 <5 µs；UART 10.4 ms 才是瓶颈 |
| OLED 整屏 / 局部 2 页 | 23.2 ms / 5.8 ms | 只在空闲刷 |

**结论**：CPU 总占用 <3%（含协议/显示），余量极大；不引入 RTOS、不做复杂缓存优化，把复杂度留给精度。

### 9.2 端到端时间预算（P0–P7）

| 阶段 | 内容 | 耗时 |
|---|---|---|
| P0 | 继电器归位/换档（静音 5 ms + 稳定 10 ms） | 15 ms/次 |
| P1 | 粗测：100 Hz/1 kHz/10 kHz 每档 N=64；100 kHz N=96 | 100 Hz 40 ms / 1 kHz 4 ms / 10 kHz 0.4 ms / 100 kHz 0.08 ms（96/1.2 MSPS） |
| P2 | 判型/选频/选档（CPU） | 0.1 ms |
| P3 | 自动量程重试（≤3 次，每次 = 换档 15 ms + 验证采集 1 块） | 见固定开销 |
| P4 | 精测：K 块，N=1024（100 kHz N=1008） | K·N/fs（100 Hz 640 ms/块 … 100 kHz 0.84 ms/块；K=32 → 26.88 ms） |
| P5 | 校准反解 + 参数提取（CPU） | 0.05 ms |
| P6 | 串口输出一行（实测 133 字符 @115200） | 11.55 ms |
| P7 | OLED 局部刷新 2 页 | 5.81 ms |

**固定开销** = 4 档粗测 + 15 ms 归位 + 3×15 ms 换档 + P6（11.55 ms）+ P7（5.81 ms）：
100 Hz **237.4 ms**、1 kHz **93.4 ms**、10 kHz **79.0 ms**、100 kHz **77.7 ms**。

| 场景 | 精测采集 | 固定开销 | **最坏总时长** | 指标 |
|---|---|---|---|---|
| 100 Hz（含 1 MΩ、自动量程） | 640 ms（K=1） | 237.4 ms | **877 ms** | 无硬限；接近 1 s，余量 1.14×、超时 950 ms |
| 1 kHz（R 发挥项 0.5%） | 512 ms（K=8） | 93.4 ms | **605 ms** | ≤1 s ✅ |
| 10 kHz | 102.4 ms（K=16） | 79.0 ms | **181 ms** | ≤1 s ✅ |
| 100 kHz（发挥项） | 26.88 ms（K=32×0.84 ms） | 77.7 ms | **105 ms** | ≤1 s ✅ 余量 9.5× |

**100 Hz 是全局最紧的约束**：N=1024 单块 640 ms，1 s 内最多 1 块 → 粗测必须 N≤128（推荐 64）、精测 K=1。若需要 100 Hz 的多块平均，应改 N=512×2 或 N=256×4（总时长相同、块间可平均）。

### 9.3 自适应块数与提前停止

- 默认块数：`K_default = {100 Hz:1, 1 kHz:8, 10 kHz:16, 100 kHz:32}`；
- 类型覆盖：C/L 基础指标（2%）只需 1σ≈0.3% → `K=2` 即可；R 发挥项（0.5%，3σ）保留默认；10 pF/100 kHz 需 `K≥4`（小信号 + 高阻档噪声大）；
- **提前停止**：K≥2 时，若前 2 块 `spread_lin < 0.1%` 且 `spread_ph < 0.02°`，则停止（典型 1 kHz 会停在第 2 块，省 75% 时间）；
- **超时保护**：`meas_auto` 入口记录 `t_start`，超过 **950 ms** 强制结束并返回当前最优结果 + `err=TIMEOUT`（保证 ≤1 s 承诺；100 Hz 877 ms 留 73 ms 余量）；
- 全部参数在 `board_config.h` 的表里，不散落在代码中。

### 9.4 扫频模式（发挥项与调试）

- 频率生成：`TIM2->ARR = 84e6/(S·f0) − 1`（先定 S，再由 f0 取整 ARR）；实际 `f0_act = 84e6/(S·(ARR+1))`；DDS 频率字 `FREQREG = round(f0_act·2^28/8e6)`；
- 频率格点（由 ARR 整数步进）：Δf = f0²·S/84e6 → 100 Hz 1.9 mHz、1 kHz 0.19 Hz、10 kHz 19.05 Hz、100 kHz **1 428.6 Hz（1.43%）**；
- 可达范围：S=16 时 f0 ≤ 87.5 kHz、S=12 时 ≤116.7 kHz（fs≤1.4 MSPS）；DDS 上限（MCLK 8 MHz）按 1 MHz 内使用；
- 扫描点数由 `SCAN f1 f2 n` 指定，输出 CSV；每点只做**粗测块**（N=64）即可，适合找谐振点/看电容频率特性（D 随 f 变化），不用于正式精度指标。

**需要硬件/实物确认的清单（12 项，对应 `afe.md` §12）**（软件无法自行决定，交付时标注）：

1. TIM2_TRGO 触发是否上板可用（R1）；
2. 复位期间 ULN 输入是否存在下拉/误吸合（R3；**ULN2803 无外部下拉为推断**）；

### 13.3 公式汇总

```
测量母公式（定稿）：     Zx = −Zf_eff(f)·(m1/m2)/α          α = m1/m2 = g1/g2
标定求解精度：         **全程 double**（cal.c 不复用 float；记录按 §7.6 存 double 复数）
反馈阻抗：               Zf_eff(f) = Rf/(1 + j2πf·Rf·Cf)
观测模型：               Zm = Zs + k·(Zx ∥ Zp)
开路：                   Z_open = Zs + k·Zp
双负载：                 W_i = Zm_i − Z_open，A_i = W_i/k = −Zp²/(Zstd_i+Zp)
                         Zp = (W2·Zstd2 − W1·Zstd1)/(W1 − W2)      （只用比值，与 k 无关）
                         k  = W1 / (−Zp²/(Zstd1 + Zp))
                         Zs = mean( Zm1 − k·(Zstd1∥Zp), Zm2 − k·(Zstd2∥Zp) )   （两点回代取平均）
反解：                   X = (Zm − Zs)/k；Zx = Zp·X/(Zp − X)（Zp 有效）或 X
S 相折叠：               A_p = Σ_k x[p+Sk]（p=0..S−1）
                         X_h = Σ_p e^{−j2πhp/S}·A_p（h=1 为基波；h=1..S−1 谐波）
S 取值：                 100 Hz/1 kHz/10 kHz 用 S=16（N=1024、M=64）；100 kHz 用 **S=12**（fs=1.2 MSPS、N=1008、M=84）
归一化：                 峰值 = 2|X_h|/N；rms = √2|X_h|/N
频率：                   fs = 84e6/(ARR+1)；f0 = fs/S；FREQREG = round(f_dds·2^28/8e6)（100 kHz：ARR+1=70→fs=1.2 MSPS；N=1008）
                         f_dds = FREQREG·8e6/2^28；C/L 换算用 f_dds 而非标称值
参数提取：               D = Rs/|Xs|；Q = |Xs|/Rs；Cs = −1/(2πf·Xs)；Ls = Xs/(2πf)
                         Cp = Cs/(1+D²)；Lp = Ls(1+1/Q²)；Rp = Rs(1+Q²)
噪声：                   σ_A = σ·√(2/N)；N=1024 时 |Z| 1σ ≈ 0.082%（|Vo|=0.05 Vrms）
```

### 14.3 一句话架构总结

> **单一 HSE 时钟源 + OPA2810/BUF634A 自动平衡电桥 + 双 ADC 同步** 构成硬件底座；软件用 **TIM2 精确相干采样（S=16/12、N=1024（100 kHz 1008））→ 16/12 相折叠 DFT（O(N) 加法，附带谐波/削顶质量指标）→ α/开路/双负载三级校准 → 表驱动量程/选频/类型状态机**，把 4 频点 × 6 档裁剪到合法且最优的工作点，在 **105 ms（100 kHz）～877 ms（100 Hz）** 内给出 **0.16% 级**的 R/C/L 复阻抗与 D/Q，并专门覆盖 **100 kHz、10 pF、1 MΩ 自动量程** 三个发挥项；全部算法可用 numpy 金标准向量在板上回归，校准数据用 sector6/sector7 双扇区 A/B+日志记录式存储保证掉电安全。
